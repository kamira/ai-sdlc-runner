## Why this acceptance is shaped differently

Three rounds running, this function's fix has carried the defect class of the thing it fixed, and
each time a review seat found it rather than the suite. Once is chance. Three times means the suite
is the thing under test, not the code.

So this acceptance verifies two separate claims:

1. the constructed states behave (the ordinary claim);
2. **the tests written for them can fail** (the claim that was missing).

Claim 2 is the one that would have caught `assert good.id in report["imported"] or
report["refused"]` — a test that passed on the exact abort its own name forbids, shipped in
CHG-20260823-45 and marked done.

## What the suite caught that I did not

`test_documented_numbers.py` failed, and it was right to. It is one of two tests in this repository
that know a *shape* of mistake rather than a specific bug — here, that a number written in prose
drifts away from the thing it counts. It has now paid for itself three times.

It is worth putting beside the rest of this document. Everything above is a test written after a
defect was known, by the person who caused it. This one knew nothing about importers and caught a
real false statement in the README anyway. The mutation table cannot do that, and says so.

## Reservations (disclosed, not waived)

1. **The mutation table tests the tests, but I chose the mutations.** Seven shapes I already knew
   mattered — six because a seat had just named them, the seventh because I noticed it reading. A defect class nobody has named yet has no
   mutation here and would not be caught by this table. This is a real improvement over the
   previous three rounds and it is not the same thing as coverage.

2. **Symlinks are not handled.** The walk descends exactly two levels, so a loop is bounded, but a
   symlink pointing outside the store is followed and nothing tests it. Named in the CHG's
   "Not claimed".

3. **`_printable` defuses control characters only.** Right-to-left overrides, zero-width joiners and
   homoglyphs pass through. An id can still be made to *look* like another id in a terminal.

4. **Concurrent writers to the target are invisible to the index.** Read once, before the loop. A
   conversation added mid-import collides with the backend's uniqueness constraint rather than
   producing a named refusal. Not new to this change; now written down.

5. **This is the fourth rewrite of this function, and three of the previous three shipped a defect
   of the class they had just fixed. So did this one.** Row 12a is defect 5 with the filename axis
   instead of the directory axis, introduced by the fix for defect 5 and caught the same afternoon
   by reading rather than by the suite or by the mutation table. Nothing in this document
   establishes there is not a fifth. It establishes that seven known classes are pinned by tests
   that have been watched failing, and that the reading pass is still finding what the tests do
   not.

6. **The mutation for row 12a was written after the defect, like all seven.** A mutation table
   proves the tests can fail; it cannot propose a class nobody has thought of. Every entry in it
   traces to something a seat said or something I noticed reading — none to the table itself.
