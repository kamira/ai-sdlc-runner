## Reservations

1. **All four findings are about work this session merged, and none turned a test red.** That is the
   same result as every round of this review, and it is the finding under the findings: the suite
   does not test declarations against the code beside them. 2020 tests did not catch a governance
   rung opening to a plain HTTP request.
2. **Criterion 10 strikes a tick in a merged record rather than re-opening the change.** The work —
   naming the answer vocabulary in the work order — is real and unbuilt, and `pm_confirm` /
   `pm_signoff` still never tell a voice which words to use; they now only refuse it for guessing
   wrong. Striking the tick is the smaller lie than leaving it, and a later record should carry the
   work properly. **This record does not.**
3. **Criterion 8's rule is still a two-phrase list.** Correctly scoped now, but a third wording of
   the same claim slips past it. Narrow on purpose — a looser match catches the ledger records that
   quote the old sentence correctly — and not a proof.
4. **Criterion 4 is a tightening on a live HTTP route.** A client approving a gate the run is not
   waiting at now gets an error instead of a queued approval. Anything doing that was relying on the
   defect, and it is still a behaviour change on a shipped surface.
