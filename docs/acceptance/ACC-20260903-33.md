## Reservations

1. **Criterion 4's scan is a phrase list of two.** A third wording of the same claim — *"the person
   who verifies is not the person who built"*, say — slips past it. Narrow on purpose, because a
   looser match would catch the ledger records that quote the old sentence correctly, and it is not
   a proof that no live text makes the claim.
2. **The ledger is deliberately outside the scan.** `CHG-20260823-16`, `docs/defect-log.md` and a
   design review all quote the sentence that was wrong at the time, which is what a record is for.
   Widening the scan to them would force rewriting the past, which `ACC-20260827-20` forbids twice.
3. **`data.md`'s new paragraph is a hand-written list of one.** It names `halt_routing` because that
   is the only project table reaching `policy` today, and it asks for the next one to be added — but
   nothing derives the list, so the next one arrives by somebody remembering. A rule that walked
   `policy`'s signatures for `Optional[Mapping]` parameters fed from `store` would be stronger, and
   is not built here.
