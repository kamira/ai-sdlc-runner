## Criterion 10 — the rule flagged its own docstring, and the scope stayed whole

The first draft matched any line naming both computed fields and flagged five: four prose
explanations — including its own docstring, which had reproduced the copies to explain them — and a
test function whose *name* contains one of them. **None was a copy.**

Two things were wrong and only one of them was the rule's scope:

1. matching the two words rather than the set literal — fixed by narrowing to the literal
2. a docstring that reproduced what it forbade — fixed by rewriting the prose

The exemption that would have hidden the second (skip the file the rule lives in) is the shape
CHG-20260903-33 got wrong, so it was not taken. **Fourth time this session** a rule fired on prose
about the thing rather than the thing; fourth time the answer was to narrow the rule, never to
reword code to satisfy it.

Proven both directions: a sixth copy injected into `test_schemas.py` → red; removed → green.

## Reservations

1. **`COMPUTED` is itself hand-written.** A computed field nobody adds to it still reaches disk.
   Criterion 5 catches the opposite mistake — a name in `COMPUTED` that `as_dict` does not produce.
   Stated, not implied.
2. **The console renders no assignments at all.** The defect seat reported that it never reads
   `source`; measured, `node_models`, `seat_models` and `assignments` appear zero times in
   `console/index.html`. The server half was a defect and is fixed; the console half is a **missing
   feature**, and building it is not a defect fix. Named in the change, not folded into it.
3. **`GET /config/nodes` now answers a real map where it answered `{}`.** Anything that read `{}`
   as “no overrides” was reading a defect, but it is a changed answer on a live route.
