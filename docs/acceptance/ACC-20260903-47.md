## Both arms, measured

```
arm 1 — the adjudication rule, over a split panel
  review_seats=None, high_risk_mode=False   3 seats   pass
  review_seats=2,    high_risk_mode=True    2 seats   undecided
  review_seats=1,    high_risk_mode=True    1 seat    pass      <- `undecided` unreachable

arm 2 — a permanent halt, same node, same operation
  ordinary_commands=()          STOPS: "names target(s) this runner does not recognise"
  ordinary_commands=("pnpm",)   no stop
```

`undecided` means nobody could settle it and **a person must**. At one seat it cannot arise. Both
movers are `settings.FIELDS` entries, under a paragraph saying settings cannot reach the
adjudication rule or a permanent halt.

## The file contradicted itself three lines apart

`settings.py`'s third bullet, added by CHG-20260903-28, is arm 2 stated accurately — *"vouches
commands, so an undeclared target stops being refused"* — directly beneath the sentence denying it.
That change corrected *"lower the seat floor and can do nothing else"* and left *"cannot touch … a
permanent halt"* standing **above its own correction**. Same shape as `ARCHITECTURE.md` defining
`asks` two lines below misusing it (CHG-20260903-43).

## Criterion 7 — the comparison, not just the mutation

```
mutation: vouching stops letting the run past
  old test (FIELDS tuple + as_dict keys)      green   it never looked
  new test (the halt, measured both ways)     RED

mutation: a settings field is renamed
  old test                                    RED     no defect present

```

The old body was red only in the false-alarm direction — **green on the defect, red on a rename**,
the fourth instance of that class corrected today. The surface check survives because enumerating
the surface is genuinely useful; what changed is that it no longer carries a name claiming to check
something else.

## Reservations

1. **No behaviour changes.** `policy`, `settings` and `engine` are untouched but for a docstring.
   Whether `review_seats=1` *should* be allowed to remove the `undecided` outcome is a separate
   question this record does not open — it makes the consequence visible, which is the precondition
   for asking it.
2. **`resolve_seats`' docstring already recorded arm 1** (CHG-20260903-35, L-49) while
   `settings.py` denied it. Two modules held opposite claims about one behaviour and nothing
   compared them; this record fixes the false one and does not add a check that the two agree. A
   rule over cross-module claims would be its own change, and it is the shape most of today's
   findings share.
