## Evidence

### Two spellings, three readers, no test


Every other mention in the repository is a historical record. The `call` fixture sends
`Host: 127.0.0.1:{port}` and every positive case rides on it, which is why the bracketed form
had no coverage to lose.

### What the review found, and what it cost

grounds. Measured:

A server bound to `::1` would refuse the `Host` every browser sends it, and the test written

## What this does not do

It does not derive `LOOPBACK_HOSTS` from `LOOPBACK`. Both seats said the derivation is one
expression and measurably equal today, and the first draft of this record was overstating when
it called that *"a design question about one of them owning the boundary"* - it is a
straightforward follow-up that would make both rules here unfalsifiable rather than checked. It
changes production code, so it is a separate record. Naming it is the correction; declining it
here is still right.

It does not fix `::1` against an `AF_INET` server. That is a defect in what `LOOPBACK` claims,
measured during this review and filed; production never passes `host`, so it is latent.

## Verdict

**Pass**, after a rewrite. The first draft asserted the overlap of two constants and would have
shipped believing it had closed a hole that both seats then opened by hand. What ships asks the
two functions the same question a browser asks them.
