## Evidence

### Two spellings, three readers, no test

```
LOOPBACK        serve             the address the server binds
LOOPBACK_HOSTS  _loopback_host    the Host header, as written
LOOPBACK_HOSTS  _loopback_origin  the Origin header, brackets stripped

```

Every other mention in the repository is a historical record - `CHG-20260823-35` counts
`LOOPBACK_HOSTS` among what a past change touched, and nothing since asserted it.

### The direction nothing covered

```
LOOPBACK gains "127.0.0.2"      tests/test_server.py   128 passed
```

A server bound to an address it then refuses as foreign, and the refusal blames the request.
`127.0.0.2` is loopback on every platform this runs on; so is `::ffff:127.0.0.1`.

### The direction that was already covered, and how well

```
LOOPBACK_HOSTS loses "localhost"
    FAILED test_our_own_origins_are_still_accepted[http://localhost:8765]
```

Measured rather than assumed - and the measurement is the interesting part. That test names
four origins as literals. It catches a value it happens to list and says nothing about the
bind list, so the coverage was of three particular strings, not of the property. The new test
reads both constants, so it follows them.

### The mutations

```
CAUGHT  the server may bind an address no request may name again
CAUGHT  the header check may be tightened below what is bound again
```

The second is caught by the new test and, independently, by the four-origin test above. It is
registered anyway: one property, and a group that recorded only half of it would say the
boundary is pinned when a bind-side edit is what slips through.

## What this does not do

It does not merge the two constants, and it does not assert the reverse containment. They
answer different questions: `[::1]` is a bracketed form that only means anything in a header
and is not an address to bind. Whether `LOOPBACK_HOSTS` should be derived from `LOOPBACK`
rather than written beside it is a design question about one of them owning the boundary, and
this record does not answer it - it requires only what must be true while both are written by
hand.

## Verdict

**Pass.** The overlap between two hand-written spellings of one boundary is now required to
hold, in the direction where a server would otherwise refuse its own address.
