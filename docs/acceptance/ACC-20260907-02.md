```
index.html:720   drawFlow(); drawLog(); drawDecisions(); drawAsk();
```

drawn. The readable, attributed, red rendering of `safety` is `drawUnsafe`, called only from inside
`drawAsk`'s suspension branches.

those words appeared was this block, and there they were `[object Object]`.

### What the guard can and cannot do, said plainly

There is no `node` on this machine, so the rendering cannot be executed here. The test asks
`_console_code()` — the page with every comment stripped, a helper that exists because *"the first
version of the guard below was satisfied by its own comment"* (CHG-20260904-11).

It asserts three things, chosen so that each plausible reversion removes exactly one:

```
"String(state.survey[k])" absent    <- the whole repair reverted
'typeof v === "object"' present     <- the map branch made dead
'seat + ": " + line' present        <- the attribution dropped
```

Both mutations trip an assertion rather than passing in silence:

```
CAUGHT  the survey goes back to being printed as [object Object]
CAUGHT  the lines stop saying which seat said them
```

This is a text guard. Saying so is part of the record: it is the strongest thing available without
a JS engine, and the mutations — not the assertions — are what make it a pin.
