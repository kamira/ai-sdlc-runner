## The end-to-end case is the one that matters

Asserting on `_class_in_force` alone would prove the resolver works, not that the walk consults it.
Same plan, two workstreams, differing only in the flags:

```
copy classed only        -> stopped at: merge — confirm at risk low …   state: suspended
copy and schema classed  -> class relaxed: merge … would have been 'confirm'
                            stopped at: done
```

The first is the safety property: a pre-authorised copy tweak does **not** carry an unassessed
schema change through the door they both pass.

## Why refusing beats applying-to-all

A bare `--change-class` over a split programme could have been applied to every workstream. That is
the runner deciding that one assessment covered work the assessor may never have seen — and doing it
quietly. Refusing costs the operator one flag and makes the claim explicit per part.

It is also the direction that cannot fail unsafely: a refusal stops a run that should have
continued, which is visible and fixable. The alternative relaxes a gate nobody meant to relax, which
is neither.

## Reservations (disclosed, not waived)

1. **A workstream is whatever the plan declares.** Two modules inside one workstream share a class,
   and nothing here asks whether they should. The granularity is inherited from CHG-20260827-18
   rather than chosen for classes.

2. **More places to type a name is not more assurance.** `authorised_by` is still whatever the
   operator typed, now once per part. Nothing verifies a person exists or agreed — the same
   reservation CHG-20260828-03 records about `by`.

3. **`combined_class` is a rule, not a measurement.** That `emergency` should win over `standard`
   for reporting is an argument, not an observation. It is written as data next to its reasoning so
   a reviewer can disagree with the rule rather than with the code.

4. **Verified by the implementer**, and the gap was found by reading a reservation the implementer
   wrote. That is an argument for writing reservations honestly; it is not independent review.
