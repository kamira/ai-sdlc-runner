1. a tree per module **deleted the run's output while reporting success**;

fixes both makes every module a commit. That was not a decision to take underneath a record that had
not considered it, so it went to a person. **The operator answered: a module is a commit.**

## Three findings from building it

**A build cannot see uncommitted work.** A tree is cut from a commit, so an edit in the operator's
working tree is invisible to it. Inherent to isolation, not a defect — and a surprise, so the run
says so before it starts. Found the hard way: a test edited the agent, left it uncommitted, the
build ran the *previous* agent, and the module loop went round **thirty-nine times** before the step
guard stopped it. The first draft of that test then asserted on `--rule`, which breaks a panel's tie
and does not choose a branch; a test that fails to reach the halt it is named for is worth more than
one that passes for another reason.

**A cycling run left thirty-nine worktrees and thirty-nine lines of path**, burying the halt message
that explained them. Summarised past five.

**`worktree.py` wrote to disk outside `paths.py`.** `test_paths` refused it. Four calls are now
declared with reasons and the artifact copy is routed — the parent through `paths.makedirs`, both
copy arguments through `paths.real`. One of the four, `shutil.which`, is not a write at all: it is
caught by a deliberately broad `shutil.*` rule that the seats asked to keep broad, and a false
positive with a reason beside it is better than a list that goes stale.

## Reservations (disclosed, not waived)

1. **Step two is not started.** Concurrency, its frontier, and the `_assemble` duplicate-`seq` scan
   are untouched. Task 5a (what `last_word` means with several builders in flight) is still
   unanswered and task 6's measurement — which might say concurrency is not worth doing — has not
   been taken.

2. **The commit message names files, not the module.** The module's name never reaches the trees:
   the engineer reports it in an answer they do not see. Naming the changed files is more use to a
   reader and needs no new plumbing, but the log does not say "alpha".

3. **A halted run keeps its trees, and they can be many.** Thirty-nine from one cycling run. They
   are evidence and removing them would take away the only place to look, but they are the
   operator's disk and nothing prunes them.

4. **The commits are the runner's.** Author is a fixed `ai-sdlc-runner` identity rather than the
   operator's git config, deliberately — a machine-made commit wearing a person's name is the
   misattribution CHG-20260828-03 fixed in the export, and here it would be durable. Whether a
   reviewer wants that is not something this change asked.

5. **Worktrees isolate the tree.** Two modules writing the same database, port or cache still
   collide. The record says so under *Not claimed* and nothing here changes it.
