## The refutation

Everything two builds of this record said about *why* a fixture was needed rested on one sentence:
pytest removes old basetemps with `shutil.rmtree` on a plain path. It was never measured. What was
measured was `shutil.rmtree` on a plain path — which does fail — and the failure was attributed to
pytest.

pytest calls `ensure_extended_length_path` first. Measured four consecutive runs of the two
chain-building modules with no fixture: `pytest-0` (84 top-level dirs, 474 entries, 17 past 259
characters, deepest 391) was removed by pytest at run 4, silently and completely.

The stranded directories that started the item are **locked**, not deep. `ensure_deletable` returns
`False` while a lock file is younger than the cutoff. All three on this machine carry one, and the
largest — 826 entries, 2026-09-08 23:43 — is a background full suite this session started and
killed.

## What this cost, and where the process failed

The item survived a seat that found it, a handoff, an ordering deliberation by **two** seats, two
builds, and four seat reads. It was refuted the first time anybody ran the thing it was about.

Three specific failures, none of them subtle in hindsight:

- **The operator measured the component and attributed the result to the caller.**
  `shutil.rmtree(plain)` failing is a true fact about `shutil.rmtree`. Nothing followed from it about
  pytest without reading what pytest calls, and reading it took one `inspect.getsource`.
- **Both seats reviewed the fix, and the first two rounds asked them to.** The prompts named the
  fixture, the warning, the numbers — and not the premise. A seat asked to refute a repair will
  refute the repair. The second round's prompt asked one open question ("anything a run refutes that
  a reading would not"), and that is the question that closed the item.
- **The stranded directories were evidence and were read as a symptom.** Three of them, all with
  `.lock`, one timestamped inside this session's own killed run. Listing the directory would have
  raised the alternative before the first line of the fixture was written.

## What is still open, and belongs elsewhere

- The three locked basetemps on this machine. `rmdir /s /q` removes them; operator action.
- The AST sweep prototyped in the second build — a guard that a chain-building module opts into the

  ever appears, it is in this record's history.
- **Whether other items in the same handoff rest on unmeasured premises.** Item 8 in that list was
  already found to contradict the shipped comment it was about. This is the second of eleven whose
  description did not survive contact with a measurement, and the ordering deliberation had already
  corrected four more.
