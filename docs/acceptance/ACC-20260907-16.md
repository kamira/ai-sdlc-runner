## Evidence

### The doctrine that stopped at the mapping

`plan.py` refuses an unknown **key** because *"ignoring them would let a setting look configured and
do nothing"*. Measured before this change, the contents of `decisions` were exempt from it:

```
{"nonesuch": "x"}            ACCEPTED   no such node
{"feedback": "elsewhere"}    ACCEPTED   offers ['done', 'more']
{"module_built": "yes"}      ACCEPTED   read, never supplied
```

`feedback` sits after `merge`, so the second was found past the one-way door, having dispatched
every ask. CHG-20260907-15 gave that run a closed record; this refuses the plan. Neither fixes the
other — the first ran to `finished` with a clean close and nothing said anywhere.

### The cost neither reviewer measured

Both chose `RunConfig` as the choke point. Neither measured that a config carrying a derived-node
decision then cannot be **built**, so `_choose`'s four guards become unreachable through the public
API — which is CHG-20260907-09's subject.

Measured: the guards stay reachable by setting the attribute after construction, and `_choose`
still returns the derived answer. The two tests keep their property and gain the new one:

```
the front door    RunConfig(..., decisions={"module_built": "yes"})    refused
around it         object.__setattr__(cfg, "decisions", …)              _choose still says "no"
```

Their comments say that going round the front door is what they are doing, and why: defence in
depth against a state the public API does not admit.

### The blast radius, measured twice

A sweep over every dict literal keyed by node ids reported **26** offending sites. All but two were
CHG-20260907-11's gate-phase pin and a change-class map — dicts that are not decisions. Scoped to
`decisions=` arguments and `*DECISIONS*` bindings: **2**, and the full suite agreed exactly.

Sizing the repair from the first population would have been worse than not sizing it.

### The mutations

```
CAUGHT  a plan may decide a node this flow does not have again        1 failed, 66 passed
CAUGHT  a plan may decide a branch the node does not offer again      2 failed, 65 passed
CAUGHT  a plan may supply a decision the run reads for itself again
CAUGHT  a run built without a plan may skip the check again
```

The first two were applied by hand as well: the group run reported *"all 6 caught"* while printing
four lines, and a summary that counts more than it shows is not evidence for the two it did not
name.

## Verdict

**Pass.** A decision is refused where it is written rather than where it is reached, in the
vocabulary of whichever door it came through, and the guards that used to be the only thing
standing between a typo and a merged change are still there and still tested.
