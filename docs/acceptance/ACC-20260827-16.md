## Why this is a knowledge entry and not a fix

The useful thing was never which of 3 and 4 is right. It is that **the two numbers count different
things and the document never says which unit it means** — so the disagreement is not arithmetic,
and no amount of checking resolves it.

That generalises. Any count with a qualifier beside it (`4 (+1 intended)`, `12 excluding retries`,
`9 of which 2 are duplicates`) is a total and a subtotal wearing one number, and the next person to
write one will make the same shape unless the rule is written down.

The alternative — picking a number so the check could be strict — would have put an invented figure
into the file that exists to record figures going stale, and the invention would then be the citable
one. KN-9's rule one level up: an unrecognised value is a failure, never a pass, and *"I cannot
tell"* must never render as *"it is fine"*.
