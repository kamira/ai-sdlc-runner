## Evidence

### The veto, upheld by both reviewers

The message said *"has a gate phase but no gate"*; the condition refused only the `after` half; and
since `before` was the **default**, the sentence was true of the twenty-one ungated nodes it let
through. Neither reviewer would overrule it. Both reached the same repair independently — make the
type able to express "no phase", so the sentence and the condition are the same statement.

### The half the veto led to

```
gated 10   after 7   before 3        ungated 21, all "before" by default
```

The default was the minority value, and a default cannot be told from a decision. A gated node
whose author forgot the phase got the shape the field's own comment calls a defect an independent
verifier found. It is a build error now, and `engine.walk` validates before it walks.

### Why the suite was blind, exactly

```
gate_when=after    halted_at='pm_signoff'   asked: True    (7 asks)
gate_when=before   halted_at='pm_signoff'   asked: False   (6 asks)
```

Same halt, one fewer question. Every test pinning that node checked where the run stopped, so:

```
pm_signoff -> before  +  engineer_selfverify -> after     2292 passed, 4 skipped, 0 failed
pm_confirm -> before  +  engineer_selfverify -> after     2 failed, 2290 passed
```

The pair evades `test_documented_numbers`' count; `pm_confirm` is caught only because its test
asserts the **ask**. That is the shape the new behavioural test copies.

### A method of mine that produced a wrong sentence

I grepped `gate_when` across `tests/`, listed four nodes no test names, and wrote "named by
nothing" into the review brief. Flipping them one at a time refuted it for `pm_confirm`: two tests
caught it, neither of which mentions the field. The finding survived at three nodes instead of
four; the sentence did not. A five-file run had also said `211 passed` for a mutation the full
suite caught in two files.

### Each mutation, checked against the test that names it

One failure each, and in both cases the failing test is the one whose name states the guarantee —
not a neighbour firing on collateral, which is how this round's first `kind` measurement went

### Four things the reviewers found unprompted

change; `engine.py:2766` shipped `gate: null, gate_when: "before"` for `intake_review` in a public
record — the exact pair the old message forbade; `docs/API.md:53` says the payload carries all
**28** nodes and there are 31; and the console reads `gate_when` nowhere, so `null` for twenty-one
nodes costs no reader anything. All four are corrected or accounted for.

### A trace of mine a reviewer corrected
