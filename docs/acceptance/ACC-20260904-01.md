## The rule that held the helper accepted a method that guards nothing

```python
def veto(self, version, gate, node_id) -> None:
    self._answering()                       # named, given nothing
    self.state.rejections.append(
        engine.Rejection(gate=gate, node_id=node_id, run_id=None, reason="veto"))
```

```
against the rule as shipped   .......... SURVIVED, 1 passed
against the rule as it now is  ##########  red
```

It asked whether the token `_answering` appeared and whether the token `run_id=` did. `run_id=None`
is the literal `Approval`'s docstring calls *"the wrong one for an answer typed into a console after
a stop"* — the exact value the change was written to stop two methods passing.

**Third rule of mine this round that counts what is written rather than what must be true**:
`-41`'s was blind to a missing append (fixed by `-46`), `-46`'s is blind to a keyword-form
resolution (the seat's L-19, still open), and this one was blind to an empty argument list. The
common shape is a rule whose subject is the **text of the code** rather than the **property**, and
three consecutive attempts to write the second produced the first.

## Reservations

1. **The engine's up-front refusal is unchanged and still correct.** A malformed entry that reaches
   the ledger by any other route still bricks the run; this closes the one door that was producing
   them, not the ledger's shape. Whether an append-only decision ledger should have a withdrawal
   route is a real question and it is not this record's.
2. **`policy.GATES` membership is still not checked at the door.** A well-formed but non-existent
   gate name — `"plan_confirmd"` — is refused by `_answering` only because it does not match the
   suspension. If the run were waiting at no gate, it would pass. Named rather than fixed: the
   suspension check covers every reachable case today and a second check would need its own reason.
3. **Four more findings from the same seat in the same round are open** — L-16, L-17, L-18, L-19 —
   and each gets its own record rather than being folded in here.
