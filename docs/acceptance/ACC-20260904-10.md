## L-41 - and the exemption that is a rule

now `tokenize` for comments and `ast` for docstring bodies - stated, rather than approximated by

column 1`. **Exempting it by name would have been an allowlist**; what tells a machine's position
from a reference into this source is the `column` that follows the number, so that is what the rule
says. Both directions are asserted on planted sources.

## Reservations

1. **The page's count is a literal.** `All 15 keys` is checked against `len(SUSPENSION_FIELDS)`, so
   growing the union turns the guard red and the page has to be edited - which is the intent, and
   is also one more hand-maintained number in a repository whose `test_documented_numbers.py`
   exists because of hand-maintained numbers. The alternative, generating the sentence, would make
   the page say whatever the code says and check nothing.
2. **`prose_of` reads `src/` only.** `tools/` and `tests/` still cite line numbers freely, and
   `CHG-20260904-06`'s Risk section overstated the ban's reach in the same way. Not widened here:
   the ban's warrant is that a comment is read at whatever the file says today, and that argument
   is the same for `tools/`. It is a separate change and it is stated so somebody makes it.
