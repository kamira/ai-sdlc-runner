existed. That evidence is most of what makes the ones still standing worth reading: a list of
limitations is credible in proportion to how obviously nothing has been quietly removed from it.

`enforce_admins` is **off**. Checks must pass, and an admin can still override — so "CI is advisory"
is wrong, and "CI is enforced" would be an over-claim in the other direction. The replacement says
both halves.

record that over-states a safeguard is worse than one that under-states it.
