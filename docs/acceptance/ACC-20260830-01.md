## The measurement, done the way the last acceptance said to

`ACC-20260828-24` concluded my probe *"should not have existed"*. This change did it with
`mutation_check.py` directly: write the mutations, point them at the existing test file, read the

## Two mistakes, and they are the same mistake

**A mutation that changed nothing.** Replacing `bool(presented) and compare_digest(...)` with
`compare_digest(presented or "", ...)` agrees on every input, because the token is never empty. It
reported `NOT CAUGHT`, which reads identically to a missing test. The harness cannot tell those
apart — its docstring says so — and the judgement fell to me.

**A test that could not fail.** The query-string test sent `token=""`, and `_guard` consults the
query string only when the header is *absent*. An empty header is not absent, so the test passed and
the mutation stayed `NOT CAUGHT` **with the test in place**. That is the useful detail: the mutation
did not merely find a missing test, it found a present one that was arranged beside the branch
rather than through it.

Both are the same error in different directions — assuming that a thing which *looks* like it
exercises a guarantee does. That is the defect this repository has been recording all along, and it
is now the fifth instance this session, the third of them mine.

## Reservations (disclosed, not waived)

1. **Eight guarantees, one function deep.** They came from reading `_guard`, `accepts` and `_body`.
   `server.py` is 943 lines and the routes *behind* the boundary — version conflicts, the 409 on a
   second walk, the attachment path — have their own refusals and were not surveyed. This is the
   front door, not the house.

2. **A spy is not a timing measurement.** It proves `accepts` calls `compare_digest`. If that
   function were swapped for something variable-time the test would still pass. Timing assertions
   are not reliable in a suite, so this is the best available and it is weaker than the guarantee.

3. **The malformed-body test pins the wording, not the status code.** It asserts the refusal is not
   a 500 and that it says `"not JSON"`. If that wording changes for good reason the test fails for a
   bad one — a cost this repository usually accepts, but it is a cost. (**WRONG** — an earlier draft
   of this reservation said it asserts `409`; it does not, and the row above said the same — that
   row was changed silently. Both corrected in CHG-20260830-05, after the review panel's conformance
   seat read the test against the record; marked in this form in CHG-20260830-06.)

4. **Five guarantees were recorded without being re-argued.** Their tests exist and the mutations
   confirm they notice one specific break. Whether each pins the *whole* of what it claims was not
   examined.

5. **Verified by the implementer.** The three holes were found by the harness rather than by
   reading, which is the part worth keeping: reading `_guard` carefully did not surface any of them,
   and two of the three sit directly under a comment explaining why they matter.
