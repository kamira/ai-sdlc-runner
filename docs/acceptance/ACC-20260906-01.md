### Where the engines agreed, and where they did not

Both said defect on both findings, and both named the same refusals. Three differences, all
recorded and all resolved by measurement rather than by preference:

1. **Keep `--grep` or drop it.** `codex` said drop it — it searches the body, so do not use it.
   `fable` said keep it as a **prefilter** and decide on the subject, because a prefilter cannot
   admit what the subject check rejects, and dropping it reads the whole log into Python on every
   resume. `fable`'s reading holds: `codex`'s objection is to using `--grep` as the decider, which
   the fix does not do. Kept.
2. **What the fix breaks in the harness.** `fable` measured that the change would leave a
   registered mutation `ANCHOR GONE` and would silently blunt the `--fixed-strings` test; `codex`
   did not raise either. Both are in the change, and running the group afterwards found **two more**
   stale anchors neither seat predicted.
3. **What each could measure at all.** `codex` could not run a command in this environment — a
   managed policy rejected every one, even under a writable sandbox — and said so rather than
   adopting the transcript it was handed. Its review is a reading of the source; `fable`'s is a run.
   That is complementary rather than redundant, and it is recorded because it bears on how much each
   verdict carries.

### Three things this change got wrong first, all caught by running it

- **The probe's ordering.** Reading the local tip first made an existing test fail on the wrong
  refusal. The remote is asked first now.
- **Three stale anchors.** The harness reported `ANCHOR GONE` and said that is not the same as
  caught. Re-anchored, and two refusals the rewrite introduced are newly pinned.
- **A refusal with nothing behind it.** The multi-ref check was `NOT CAUGHT` until a test drove it
  through a stubbed `_run`. Adding a guard and no test for it is the shape the last three rounds
  have been about, and it appeared in the change that fixes two instances of it.

A fourth was self-inflicted and is worth recording because it has now happened four times: a
heredoc turned an escaped tab into a real one inside a string literal, and the write landed **before**
the parse check caught it. The repair validates before writing. That ordering is the lesson, not the
escape.

## Verdict

**Pass.** Both probes now describe the postcondition rather than the action — `effects.py`'s own
rule, which both of them were breaking. Fourteen of fourteen mutations caught, including four that
did not exist or did not apply before this change.
