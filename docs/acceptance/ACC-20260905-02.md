### The mutations

```
CAUGHT  D6.2 goes back to having one line binding it
CAUGHT  a definition is any bold anywhere, not one that starts a line
CAUGHT  the effects report row goes back to naming three of four fields
```

**The first one did not pass on the first attempt, and what stopped it was this file.** The run
reported:

```
NOT CAUGHT D6.2 goes back to having one line binding it
             48 passed in 5.04s
```

`labelled_ids_in` originally matched the bold label *anywhere on a line*, and scanned every markdown
file under `docs/`. This acceptance record, in the paragraph explaining what the rule matches, wrote
the pattern out as an example. That sentence is under `docs/`. So deleting the real label from
`CHG-20260822-04.md` left the id still "defined" - by the prose describing the guard that was
supposed to notice.

This is the same defect the eleventh round has been finding all the way through, and it arrived here
in the acceptance for the change that fixes it: **a guard whose subject is the text rather than the
property, kept alive by its own author's account of the defect.** It was found by the mutation and
by nothing else; the suite was green, and so was the guard.

Two repairs, because either alone leaves the shape intact:

1. **The rule.** A definition is a bold label at the **start of a line** - a list item or a heading.
   Prose that quotes the pattern mid-sentence is no longer a definition. The registered mutation was
   re-anchored onto the new rule, so reverting the anchoring is itself now a caught mutation.
2. **The record.** The floor test's plant is assembled from fragments, so
   `test_documented_numbers.py` never contains the string it forbids - and the plant it assembles is
   precisely the sentence this file wrote by accident.

`test_the_id_rule_can_see_an_id_that_lands_nowhere` is the floor under all of it: the guard's two
searches are over `src/` and over `docs/`, and if either ever finds nothing the comparison passes
vacuously. The floor drives planted text through the same two functions rather than over the live
tree.
