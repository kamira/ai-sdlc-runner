## What these tests do not do

They do not prove the panels render. There is no JavaScript engine here, so nothing in this suite
can. What they prove is that the chain which must exist for rendering to happen has not been cut -
and that is the property that was missing, because deleting the whole chain used to leave the suite
green.

Stated in the module comment and in each docstring, not only here. A structural test that reads as
a behavioural one is worse than no test, because somebody will delete the real check believing this
covers it.
