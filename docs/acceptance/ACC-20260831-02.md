## The shape of this round

Round 6's veto was a knob that disarmed the detector. The fix made the guard read both record paths.
**That fix made the mutation harness answer the same thing always** — during a run there are two
records with two owners, so the guard failed on unmutated source and `-x` stopped every mutation
there. Three rounds in a row the instrument has been broken by the fix for the previous round's
finding about the instrument.

The measurement that settles it is the defect seat's, and it is the right shape: add a mutation
nothing can catch, and see whether the harness says so. It did not. It does now.

## Every boundary rule so far was right about English

That is the durable finding. `void`/`avoided` was caught in English. What was not caught, three
times, is that the same rule was wrong in Chinese:

- `\b` against `\w` puts no boundary between 通過 and an adjoining `failed`, so a refusal read as a
  pass.
- Comparing vocabulary entries could not tell 未通過 (one word) from 通過／未通過 (two).
- The status matcher, which never had the rule at all, read 未完成 as 完成.

This repository is operated in Chinese and its vocabularies carry Chinese words. Sixteen heads are
now pinned in two tables, because the English cases pass under every rule tried so far and therefore
prove nothing about the next one.
