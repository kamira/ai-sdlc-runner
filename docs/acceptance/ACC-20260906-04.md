## Evidence

### The field reached nobody, measured

Every load of `.instruction` in `src/` — three of them in its own module (a type check and a sort
key), one at the write site, and **zero** in the console:

```
attachments.py:218/263/264/267/340   server.py:385   console/index.html: 0
```

and the row it rendered carried filename, media type and size. `KN-8`: *"A comment describing
behaviour is a claim … either make it true or delete the sentence."*

### The disagreement, and why nothing landed on the filename question

`codex`: escape control and bidi characters at the console boundary. `fable`: change nothing.
Re-measured here, and `fable`'s two facts hold:

```
raw NUL / ESC / newline on the wire : False   — json.dumps already escapes C0
raw U+202E / BOM on the wire        : True    — only these travel as themselves

CHG-20260823-47:213 / ACC-20260823-47:148   the terminal defuses C0/C1 only, and that was accepted
tests/test_cli.py  test_the_terminal_and_the_console_name_the_same_thing
```

So most of `codex`'s proposal is already done by JSON, and the remainder would defuse bidi on one
human surface and not the other — against a guard whose subject is that the two agree.

**The rule is that a fix needs both engines. They did not agree, so nothing landed.** That is the
rule operating rather than a preference of mine, and the reason is in the record so the next round
starts from the evidence instead of the question.

`fable` could not render the RTL case — the browser pane refuses `file://` and `data:` URLs, and
serving it would have meant the background job it was told not to start — and said so rather than
asserting it.

### The guard's first version did not hold, and the mutation said so

```
NOT CAUGHT  the console stops saying where a document came from
```

`assert "f.instruction" in page` survives a mutation that replaces the condition with `false`: the
identifier is still there, in the branch that no longer runs. The guard's subject was the text; the
property is that the field decides what the row says. It asserts the **read** now — `"f.instruction ?"` —
and is caught.

This is the same shape the last four changes have each hit once, and it appeared here in a
five-line guard.

### A group name that swept in four unrelated mutations

The first registration called the group `provenance`, which already existed. The run then reported
four failures from `test_documented_numbers.py` that had nothing to do with this change — including
one `NO BASELINE`, because the README count was not yet updated. Renamed to
`attachment-provenance`. Worth recording: a group name is an address, and reusing one silently
widens what a `--only` run means.

### A fourth guard, on a comment

`test_the_scanner_leaves_no_string_open_on_the_real_page` went red on a four-line **comment**. The
console page is scanned by something that cannot parse JavaScript and says so — its docstring:
*"What it can do is say when it has lost track, and this is that: at the end of the real page it
must not still be inside a string."* An apostrophe in `` `Attachment.instruction`'s `` opened a
string it never closed.

Bisected rather than guessed — removing each of the four lines in turn:

```
removing line 501 -> 1 passed     // Where the document came from … `Attachment.instruction`'s …
removing line 502 -> 1 failed
removing line 503 -> 1 failed
removing line 504 -> 1 failed
```

The apostrophes already in that file happen to pair up; a fifth broke the parity. The comment is
rewritten without one. Recorded because the failure was in prose, in a file where prose is the
usual place to explain things, and because bisecting took one command where reasoning about the
scanner would have taken several wrong turns.

## Recorded rather than bundled

- **No test posts to `/attachments` over HTTP.** `grep -rln '"/attachments"' tests` is empty, so the
  row shape `docs/API.md` documents has no executable pin. Found by the `fable` seat in passing. It
  belongs with the raw-socket fixture `CHG-20260906-02` added, not here.
- **R12-6, the per-upload walk cost.** Both engines call it the design rather than a defect; the
  console-side batching that would reduce it is its own change.

## Verdict

**Pass.** One comment became true and is pinned by a guard that fails when the wire is cut. One
question is closed with a measurement and a sentence rather than a change, because the engines
disagreed and the evidence favoured leaving it alone — and the reason is written down so it does not
have to be re-derived.
