## The reproduction

```
policy.adjudicate_grade({m1: high, m2: high})  ->  outcome=pass   grade=high
policy.adjudicate_grade({m1: low,  m2: low })  ->  outcome=pass   grade=low

cli.py     printed `outcome` alone       both runs print `pass`
console    `a.grade || a.outcome || "?"`  prints high / low
```

`adjudicate_grade` returns `outcome="pass"` for **every** grade it settles, so `outcome` alone
carries none of the information the panel exists to produce. CHG-20260901-18's title is *"the grade
a panel decides reached nothing that names it"*; it fixed the console and the terminal was never
swept — CHG-20260903-36's shape again.

`cli.py` also named `risk_agreed`, `risk_settled` and `risk_proposed` **zero times**, so the grade
the run ended up governed by reached no terminal line at all.

## Criterion 5 — why 2094 tests were green over it

The two tests pinning the footer's panel line both use `lead_review`, a **seat** panel, whose
adjudication carries no `grade`. They were green either way. A guard over a shape the defect cannot
reach is not a guard against it — recorded as a measurement (`policy.adjudicate(...)` asserted to
have no `grade` key) so that if that ever changes, the note is revisited rather than quietly wrong.

## Criterion 6 — and the third guard was checking the wording

```
the footer prints outcome again          ██████████  red
the console stops preferring the grade   ██████████  red
the settled grade goes back to nowhere   ░░░░░░░░░░  SURVIVED → ██████████  red
```

It asserted `"risk_settled" in inspect.getsource(cli)`. Replacing the guarding `if` with `if False`
left it green: the string was still there and could never be reached.

**Written ten minutes after ACC-20260903-47 recorded the fourth instance of exactly that trap.**
Knowing the pattern did not prevent it; running the mutation did. The guard now reads the
**condition** — the line must sit behind a test mentioning the value it reports, so a constant
condition fails.

## Reservations

1. **Criterion 3's guard is structural, and says so.** A behavioural version needs a grading panel
   driven through the CLI with a model registry; the check asserts the weaker property (the line is
   conditioned on what it reports) rather than that the line appears in a real run. Stated rather
   than pretended — the whole point of criterion 6 is that a guard's reach is measured, not
   assumed.
2. **A terminal line changes.** Anything parsing `panel:` lines for the literal `pass` will now see
   the grade. That is the defect being fixed rather than a regression, but it is a change to
   output somebody may be reading.
