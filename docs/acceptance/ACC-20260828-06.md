## A mutation that proved nothing, and how it showed

The first draft of the third mutation replaced only the **first line** of a two-line message. The
words the test asserts — `was NOT checked` — live on the second line, so the mutated code still
printed them: the guarantee was never made false, the test correctly stayed green, and the run
reported **NOT CAUGHT**.

Read quickly, `NOT CAUGHT` says the test is weak. Here it said the *mutation* was weak. That
distinction is not something the tool can make — `tools/mutation_check.py`'s own docstring warns
that its first importer mutation rebound a dict to an equal dict and would have reported the same
thing — so it is recorded here where the next reader of that table will be.

Rebuilt to remove the message outright, and then caught.
