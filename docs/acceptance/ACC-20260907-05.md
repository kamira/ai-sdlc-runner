## Evidence

### The request and the check, twenty lines apart

`option_request` is what this runner sends a model:

```
Propose at least 3 concrete, different options a person could pick between.
```

`read_options` reads the answer to that question and counted `len(options)`. Three copies of one
label therefore answered a question that had asked for three different ones — and the check's own
docstring says it exists because *"one is a decision wearing a question mark"*, which is exactly
what three copies of one label are.

This is not the ledger disagreeing with the code. It is **one module's request disagreeing with the
same module's check**, and the word never implemented — *different* — is in the sentence the runner
sends.

### The correction to codex, which made the finding stronger

codex cited `CHG-20260823-13` for the phrase *"at least three concrete, different options"*.
Measured:

```
grep -ci 'different options' docs/changes/CHG-20260823-13.md   ->  0
grep -rn 'concrete, different options' src/                    ->  intake.py:264
```

The phrase is not in the record. It is in the module, in the request. A record saying one thing
while code does another is the ordinary shape; a module asking for something and then not checking
for it is harder to defend, and it is what is actually here.

### The message had to change with the check

It said `got {len(options)}`, so refusing three identical labels would have read *"asked for at
least 3 and got 3"* — a sentence contradicting itself while enforcing a rule. Both numbers are
reported now. Criterion 5 exists because the first draft of this change moved the condition and
left the sentence, which would have been this round's own defect shipped inside its repair.

### The judgement that could go the other way, recorded as such

`["Fast", "fast", "Slow"]` is accepted. Case-folding would catch a model repeating itself in a
different case, and would refuse identifiers, flags and filenames that legitimately differ only in
case — while still missing a model repeating itself in different words. Exact string is the
boundary that needs no new policy; if a later round wants a stricter one, this is the line it will
argue with.

## Verdict

**Pass.** The check now counts what the question asked for.
