## Criterion 5 — the rule passed twice by examining nothing

Both found by mutating the sentence and watching the rule **not** go red.

1. **Markdown emphasis inside the phrase.** The file writes `**stops** at every grade`; the rule
   searched for the literal `stops at every` and matched **nothing at all** in it. It looked like a
   working rule only because the other document is written plainly.
2. **`"merge" in "merging"` is `False`.** The fifth letter is an `i`. The rule assumed a document
   naming the act would name the gate, and I asserted that substring twice while reasoning about
   why the mutation survived. The measurement settled it both times; re-reading did not. Gate ids
   and prose are two vocabularies and the rule now knows both.

## Criterion 6 — the second finding reversed when it was measured

`session_record` says it records the command *"as the first event"*. It does not: `events = []` and
the first append is the child's output; the command is `header["command"]`.

**The obvious fix is wrong.** `render_cast.py:107` already reads `header["command"]` and renders it,
so emitting the command as event 0 would print it **twice** on every page. The effect the sentence
promises is delivered by a mechanism the sentence misnames. The sentence is the defect — the
recorder is left alone, and criterion 7 says so as a task rather than leaving it implied.

## And the first edit made the document worse

The first `ARCHITECTURE.md` fix narrated its own revision history inside the section that should
state what the gates do — and put the wrong phrase back into the file the rule polices. Rewritten as
a statement. Recorded because it was caught by reading the result, and it would have shipped.

## Reservations

1. **No behaviour changes.** `policy.GATES` is untouched. Whether merge *should* halt at medium is a
   separate question this does not open.
2. **The rule reads prose, and prose is not a closed language.** `_forms` covers the ordinary
   inflections of a gate id; a document that says *"the merge step"* is covered, one that invents a
   synonym is not. The floor makes the rule prove it can find a gate in a sentence and prove it
   returns nothing for a sentence naming none — which is the guard against the failure this change
   found twice, not a claim of completeness.
