## Evidence

### The definition, and the clause that was never implemented

```
engine.py:289   STOPPED = "stopped"   #: ... a permanent halt, or an effect that failed
engine.py:392   state: str = FINISHED
```

Driven before the change, with the fixture `tests/test_cli.py` already uses:

```
halted_at    record_module
halt_reason  effect failed at 'record_module': effect 'tick' ran but its postcondition is still
             not true
state        finished
```

### Where `finished` went, which is why this is R-1 and not a nit

Three surfaces read `report.state` and none has another source: `cmd_run` (whose only
state-dependent branch is `SUSPENDED`, so the terminal said nothing), `RunState.state` and the
console through it, and `conversation.close(state, …)` — the durable record.

A run whose `pr` effects half-landed — branch made, commit written, push done, the pull request
not — reported that it finished in all three.

### The precedent, which codex found and which settles it

`CHG-20260827-22` made this call for the other half of the same sentence: a permanent terminal used
to report a normal finish, and it was changed *"because that is exactly the distinction the state
vocabulary exists to draw."*

So this is not a new decision. It is the same one, applied to the clause of the same definition
that was left behind.

### Checked for reversion, three ways

- `CHG-20260905-01` touched this exact `except` block — to preserve `exc.outcome`. It neither chose
  nor discussed `FINISHED` for a failed effect.
- No test pinned `finished`. `test_the_engine_records_a_halted_nodes_partial_outcome` asserts the
  halted node, the applied effects and the reason, and never the state — which is what makes this
  an uncovered defect rather than a tested decision.
- `server` already admits `STOPPED` on both recovery paths (`start` at :344, `instruct` at :377),
  so nothing recoverable before is stuck now.

### Scoped out on purpose

`cmd_run` still returns `0`. A non-zero exit for a stopped run is a behaviour change for anything
scripting this command, is not implied by naming the state correctly, and belongs to its own
decision. Written down so the next reader sees it was weighed.

## Verdict

**Pass.** The state vocabulary now draws the line its own definition says it draws, on the second
of the two cases that definition names.
