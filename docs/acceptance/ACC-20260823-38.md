## The reservation: one emitter nobody guards

`_script_json` is called for **both** script payloads, but only `__TURNS__` has a test that notices.
The `fable` engine removed the `__RAIL__` call and all 81 conversation and recording tests still
passed.

Exposure is genuinely low — the rail carries node ids and clock strings, not model-authored text — so
this is not the same severity as the hole this change fixed. It is nonetheless an **unguarded emitter
site in the change whose entire subject is unguarded emitter sites**, and that is worth writing down
rather than rounding off.
