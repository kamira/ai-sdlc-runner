## Three of my own instruments measured the wrong thing

Worth recording because all three are this review's own subject, in the work that fixes it.

1. **A name collision my search could not see.** `opened = ", ".join(policy.seat_names(seats))`
   shadowed `opened: List[object] = []` twenty-seven lines above — the seat panel's `seen` list.
   `", ".join(["conformance"])` is `"conformance"`, so the failure surfaced as
   `'str' object has no attribute 'append'` in a different function. The `awk` range I searched
   with stopped at the first nested `def`.
2. **A guard that restated the code instead of driving it.** The first version of the attribution
   test copied `walk`'s block into itself and asserted on the copy. Both mutations of the real code
   survived it. It drives a real walk now, and a second test captures what reaches the
   conversation.
3. **A count read before the thing it counted.** `results.append((len(asked), edit(...)))` —
   Python evaluates the tuple left to right, so both menu orders reported **0** confirmations and
   the test that exists to show one order skips the question showed neither doing anything.

## Reservations

1. **The composition is recorded, not refused.** Nothing rejects a run whose panel was reduced
   below the floor *and* whose gates were relaxed by a class, and no surface shows the pair. That
   is the state that reaches `finished` on a change three seats rejected. It is in *Known gaps*
   with its measurement; closing it is a different record and a design question, not a fix.
2. **`serve` still never asks.** `tui.confirm_high_risk` has two call sites, and `server.py`
   mentions `SEAT_FLOOR`, `confirm_high` and `review_seats` zero times. The console reads the file
   and opens whatever it says. This record makes the run *record* the crossing; it does not put a
   question in front of the person who starts it there.
3. **The vouch line reports the target, not the payload.** It names the target string and the
   vouched word. It does not say what `_suspect` did or did not catch — and measured, `_suspect`
   refuses `python.exe -c "import shutil; shutil.rmtree(1)"` while passing
   `__import__(...)` spelled the same way. That distinction belongs to `policy`, not here.
