## Reservations

1. **The sbpl claim was not verified on macOS.** That sbpl has no escape for `"` inside a string
   literal is CHG-20260828-25's assertion; this ran on Windows and could not check it. Refusing is
   safe either way — if an escape does exist, this is merely stricter than it needs to be — and
   that is the only reason it shipped without the platform to check it on. A macOS reader should
   treat this as the thing to falsify first.
2. **The `/tmp` grant is unchanged, and that is smaller than L-36 asks for.** `_seatbelt` still
   grants the **host's** `/tmp` at `write: none`. Narrowing it to a per-run directory needs `TMPDIR`
   plumbed into the child's environment. What shipped is that the module stops describing a boundary
   it does not draw — a documentation fix where a behaviour fix is available, and the record says so
   where a reader will see it rather than in a footnote.
3. **The blocklist is one character, and CHG-20260828-25 proposed two.** The deviation is recorded
   in the record and in the source: refusing `\` breaks
   `test_the_macos_profile_is_generated_from_the_same_policy`, because `wrap` computes `root` with
   `os.path.abspath` and that uses the host's separators no matter what `system=` says. **That is
   itself a smell** — a function told which platform to build for, computing its path with another
   one's rules — and it is not fixed here.
4. **`#99` is not adopted.** `CHG-20260828-04` and `-05` propose a conformance suite for the sandbox
   mechanisms, which is what would have caught both halves of this record, and they are still
   `Proposed` on a draft branch. They are named in the record rather than quietly left, but this
   change does not build them and nothing in the ledger obliges anyone to.
