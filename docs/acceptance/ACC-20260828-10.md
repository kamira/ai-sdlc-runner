and two runs show it. What replaced it is a *different property* from the one the reservation wished
for, so the closure names the difference instead of implying the wish came true.

unchanged. The *concern* behind it is covered elsewhere, and saying so is useful; striking the
sentence would tell the next reader that file had been rewritten, which would be false.

The distinction matters more than either reservation: **a closure is a claim, and a wrong closure is
worse than an open gap** — an open gap gets looked at.
