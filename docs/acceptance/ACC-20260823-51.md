## Three more of my own, while fixing five of my own

**The headline test passed against the defective code.** The first latch test did not pre-seed, so
round one built `alpha` by the ordinary route, `remaining` emptied, the engineer was never asked
twice, and no empty answer was produced. A test for a latch that never reached the latch — one layer
up from the mistake it was written to replace. Found only because I ran it against `origin/main`
expecting red and got green.

That is the fourth time in two days that **running the new test against the old code** was the step
that caught the error. It is more reliable than the mutation table, because it questions the
scenario rather than the assertion.

**A patch script truncated `tools/mutation_check.py` to zero bytes.** `io.open(path, "w")` truncates
before validating its arguments. Restored from git. The lesson is not the typo — it is that I
overwrote a file without looking at it first, which is the one thing the operating rules I work
under name explicitly.

**A stale mutation anchor**, from renaming `cwd` to `config_cwd`. The tool reported `ANCHOR GONE` and
failed the run rather than scoring it as caught. That part worked as designed.
