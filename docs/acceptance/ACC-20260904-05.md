## The reproduction

```
what the operator did          asks recorded   the console said
  typed one instruction              1          asked once
  attached an unrelated file         2          asked twice      <- nobody asked
  attached another                   3          -> intake.ASK_LIMIT
```

At the limit `intake.needs_options` fires and the run leaves the ask-again path for the
produce-options path. **A behaviour change, not a label**: the runner gives up on a person who was
asked once and answered by nobody, because they attached two files.

## Criterion 5 — my first framing said six methods, and three cannot reach it

I wrote the fix against *"six methods reach `_advance`"*. Measured:

```
start · instruct · attach     no `_require_suspension`   ->  can walk from an incomplete stop
approve · reject · rule       `_require_suspension`      ->  refused there by CHG-20260903-23
```

The wrong path is **`attach`**, alone. The seat's reproduction used attachments and was exact; the
generalisation was mine and it was wrong — the third time in this review that acting on a finding's
face value would have produced a fix wider than the defect.

A third guard pins the three that are already refused, so the comment cannot drift back to claiming
a reach it does not have. That is the cheap half of the lesson: when a fix's scope comes from
reasoning rather than measurement, the measurement belongs in a test beside it.

## Reservations

1. **"The requirement grew" is a proxy for "somebody was asked again".** It is the conservative
   direction — fewer forced options, more asking — and it is exact for the two paths that exist
   today. If a future surface lets a person answer the requirement without adding an instruction,
   the proxy stops matching and this is the line to revisit. Named rather than hidden behind the
   word "ask".
2. **The count is now shorter for the same sequence of clicks**, so `intake_asks_by_aspect` and the
   `reason` sentence both read lower than they did yesterday. They still agree with each other
   (CHG-20260904-03), which is the property that record established; this one changes what they
   agree on.
