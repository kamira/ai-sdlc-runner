## Reservations

1. **Six existing tests were running against a failing review panel and nobody knew.** Their fixture
   returned `{"ok": True}` for every node outside its branch map, which included the seat panel; the
   engine read that silence as a no vote, so the runs took the `review_failed` path and their
   expected suspension points were computed from it. Two fixtures now say `pass` outright. **This is
   the second-order finding of L-30 and it is arguably larger than L-30**: a defect in the engine had
   been shaping the test suite's idea of what a normal run looks like.
2. **Thirty-three fixtures share that idiom and thirty-one are untouched.** They never reach
   `lead_review`, so they are unaffected today — but the trap is still set for the next test that
   walks further. Named rather than blanket-edited: a thirty-three-file edit inside a defect fix is a
   worse trade than a recorded follow-up. **This is a live gap, not a closed one.**
3. **I shipped a wrong ruling first and a test caught it, not me.** The broad version was written,
   applied, and only the server suite disagreed. The narrow version is the defensible one and the
   measurement that supports it — one source per approval path, `server.py:323` the sole minter of
   an `Approval` in `src/` — was made *after* the failure, not before. A seat may still rule that
   the two rungs are one rung and `HALT_INDEPENDENT` should be deleted; this record takes the
   narrow reading because 「merge 永遠留一個人」 is written against exactly this rung.
4. **`test_the_suspended_report_is_returned_not_yielded` was pinned to a 1400-character window** and
   went red because this change added a comment and three lines of halt reason to the block it
   measures. Its own comment already recorded being burned once for being *"pinned to a signature
   while its name is about control flow"*; a character count is the same brittleness one layer out.
   Rewritten to read the first exit after the marker, which is what its name claims. **Fixed here
   rather than deferred, because leaving it would mean the next paragraph added to `_gate` turns a
   control-flow test red again.**
