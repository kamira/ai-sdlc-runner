## Summary

The five WinError-193 failures were a POSIX-only test-harness assumption, not a runner defect:
`CommandExecutor` correctly refused to launch a `.sh` file Windows cannot execute. Replacing the
shebang scripts with Python stubs invoked through `sys.executable` — via one shared `py_stub`
fixture — makes the command backend's end-to-end coverage run on every platform while holding all
five tests' assertions byte-identical. Recorded stub output confirms each preserved behaviour on
real values (stdin echo, `argv[1]` echo, `extra_args` ordering ahead of stdin, env inherit-plus-merge,
cwd). Suite went from 144/9/**5 failed** to **149 passed / 9 skipped / 0 failed**; `src/` provably
untouched; `doc_integrity_check.py --repo .` exit 0. **Accepted.**
