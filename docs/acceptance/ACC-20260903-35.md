## Criterion 3–4 — the rule found a flag the report did not name

The finding was about `can_execute`. Written as a rule — every `Role` capability field that
`sandbox_for` does not take must carry a written declaration — it went **red on `can_spawn`**, which
the report had described only in passing. `can_spawn` **is** enforced, by the graph's shape
(`sub_plan` is the only spawner), not by any sandbox argv, and that is now said where a reader
looking for the enforcement would look.

**A list-shaped test naming `can_execute` would have been green on `can_spawn`.**

## Criterion 5–6 — the report was right about the fact and I was wrong about the fix

My first move was to raise the floor to **2** under high-risk mode, on the ground that a panel of
one is not a panel. Checked before acting:

```
tests/test_cli.py:668, :696, :712      review_seats: 1, high_risk_mode: True
tests/test_panel_diversity.py:142      review_seats=1, high_risk_mode=True
tests/test_policy.py:155               seat_names(1) == ["conformance"]
```

**Five tests drive one seat deliberately**, and `_note_panel_diversity` is blind below two sessions
by design. Refusing it would have turned five intentional tests red for a rule nobody asked for.

So the fix is disclosure, not refusal:

```
1 seat, split   -> fail          <- seat_names(1) is the veto-holder; `undecided` unreachable
2 seats, split  -> undecided
3 seats, split  -> pass
```

## Reservations

1. **`can_execute` is still unenforced.** This records that the flag is carried rather than drawn;
   it does not make the sandbox deny exec, which needs the mechanism to do it and is a larger
   change. **A seat may rule that this should have been enforced instead**, and the record says so
   where a reader will see it rather than in a footnote.
2. **The one-seat disclosure is in a docstring**, which an operator does not read. A stronger fix
   would put it in `report.relaxations`, beside the seat-floor line already written there. Not built.
3. **Criterion 2's rule is a phrase match on one row shape.** A requirement that counts the settings
   surface in different words slips past it. Narrow on purpose, and not a proof.
4. **Twenty of the four seats' findings from this round remain unfixed**, including several that
   name a claimed property with no enforcement. The numbering collides across seats and still needs
   reconciling before any of them is filed.
