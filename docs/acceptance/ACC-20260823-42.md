## The two claims that were false at `f58a807`

Both confirmed against that revision's source:

1. *"One bad conversation no longer stops the others."* `source.read` sat **outside** the `try`,
   which caught only `ConversationError` around `into.import_conversation`. Any other dirt aborted
   the whole migration.
2. *"A file with no readable header is reported by name."* The scan used
   `Path(root).rglob("*.jsonl")`, which lists a deep store as **empty** — so the file vanished, and
   the command exited 0.

Both are fixed by CHG-20260823-45.

## The dead test

`tests/test_conversations_sqlite.py:254` defines `test_one_bad_conversation_does_not_stop_the_others`.
`tests/test_conversations_sqlite.py:417` defines a **parametrised function of the same name**, added
by CHG-45. Python keeps the second. The first is never collected — verified: 6 collected items, all
from the parametrised version.

So this change's own test for its own headline claim **has not run since CHG-45 landed**. The
replacement is stronger, which is why nothing broke and why nobody noticed. It is still dead code
sitting in the suite looking like coverage.
