## Reservations (disclosed, not waived)

1. **Written by the implementer.** Eighteen rounds, every verdict `fail`. Seventeen of the eighteen
   had their largest finding inside the previous round's fix — and this round's is that the thing
   being fixed should not have existed. That is a different kind of answer and it took five rounds
   to reach.

2. **Removing a feature is not the same as fixing it.** It is right here only because the feature
   was measured to buy nothing — 0 records rely on it. The same argument would be wrong about any
   rule this ledger uses, and it is not a precedent for narrowing a check that is load-bearing.

3. **The check now refuses a sentence that says only what a test became.** That is a real
   narrowing. The refusal spells out the remedy, it costs the author four words, and one
   `GHOST_EXCUSES` row shows a rename that also says `removed` being accepted.

4. **The bystander case in `_excused` is open**, bounded by six things, all pinned.

5. **`build_factory` still has no handler**, eleventh round running.

6. **Nothing checks that a mutation's `says` describes what its replacement does.**

7. **The harness is not in CI**, and the import probe costs 175–313s of a ~54-minute run. Roughly
   half of that is recoverable by sharing one warmed cache prefix and removing only the target's
   own `.pyc` — 0.628s per probe against 1.326s, measured. A shared cache is a shared cache; that
   is a change with its own failure mode and it is not this one.

8. **`isn't done` still reads as finished**, and `_alive`'s coupling to `_owner` is still deferred,
   thirteen rounds running.

9. **`test_concurrent_config_edits_and_model_adds_do_not_deadlock` is load-sensitive**, twelve
   rounds.

10. **`_alive` reads every dead pid as an invitation to act, and diverges by platform.** Measured on
    Windows: `0`, `-1`, `1`, `2147483647`, `2**32`, `10**30` all restore and delete. `_alive_nt`
    hands the value to `c_ulong`, which truncates it **mod 2\*\*32** silently, so `_alive(2**32)`
    asks about pid 0. On POSIX (reasoned — no host here) `os.kill(0, 0)` and `os.kill(-1, 0)` both
    succeed, so the same records refuse. One bound worth stating: the loss is capped by
    `now == mutated`, so `recover` only ever writes over a file byte-identical to the recorded
    mutated text — the unbounded case is a *live* run reading dead, which no reachable value
    produces on Windows.

11. **The lint cannot tell a real removal note from an invented one.** It has no history, and a
    note excuses whatever name it is attached to — which is how CHG-20260901-05 passed the check
    while excusing a test that never existed. Checking it would need `git log -S`, and CI checks
    out at depth 1. Stated rather than half-fixed.
