## Reservations (disclosed, not waived)

1. **Written by the implementer**, on defects somebody else measured. Nine for nine across this
   review series.

2. **The first full-suite run of this change was contaminated and I nearly reported it.** It
   returned `2 failed` — but I had reverted `cli.py` and `engine.py` underneath it while it ran, to
   do the test-the-test above. One failure was the README count (real, and fixed); the other,
   `test_concurrent_config_edits_and_model_adds_do_not_deadlock`, passes in isolation and passed on
   the clean re-run. A suite run while its own source is being edited is not a measurement, and the
   number it produced looked exactly like one.

3. **D1's structural test does not prove the routing works — it proves the two call sites agree.**
   `test_the_console_honours_the_routing_the_console_itself_wrote` drives `_permanent_halt` on a
   config built the way `make_config` builds one, which is one layer below a running server. The
   subprocess test that does cover the whole seam still covers `run` only; spinning a server for
   the second was judged not worth its runtime, and that is a judgement a seat may reverse.

4. **D2 is prose, and nothing parses it.** The test asserts a substring of an English sentence. If
   the wording changes for a good reason the test fails for a bad one. Pinned this way anyway,
   because the defect was that nobody was reading the sentence at all.

5. **D4 puts halt recipients into every exported run.** `report.halts` carries `told`, so a name
   like `sre-oncall` now travels with any `--json` output and any conversation export. Its own
   docstring asks for exactly that — *"who was told is a fact an audit asks about months later"* —
   but it is a name of a person or a rota leaving a surface it was not leaving yesterday, and that
   is worth a second reader.

6. **`change_class` still cannot reach the console**, and this change does not fix it — `serve` has
   no `--change-class`. It is named in task 3's exemption list so the next drift check does not
   silently absorb it, but it means one of the five permission ledgers CHG-20260901-15 wants in the
   console cannot exist there at all.

7. **`test_the_guard_over_the_suspension_section_reads_every_literal_there_is` will need deleting** — and it was **removed in CHG-20260904-07**, on 2026-09-04, when the condition
   below held —
   when it becomes true that reading the first literal misses nothing — it says so in its own final
   assertion. A test that instructs its own removal is unusual here; the alternative was a guard
   nobody would revisit after the third literal moved.

   > **The condition held on 2026-09-04**, and the test was **removed in CHG-20260904-07**, which
   > routed all three `report.suspended` shapes through one `engine._suspension` — so there is no
   > first literal and nothing a second reading adds. Replaced by
   > `test_the_page_documents_every_field_a_suspension_can_carry`.
   >
   > Annotated here rather than edited away: this reservation predicted the retirement three days
   > before it happened, and a record that quietly loses its own correct prediction is worth less
   > than one that keeps it.
