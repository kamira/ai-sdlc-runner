## Criterion 5 — a rule that skips is a rule that does nothing

The first version of criterion 4's rule guessed the importer's name, missed, and fell to
`pytest.skip("the importer is not a module-level function")`. **One skip out of eighty-one, and it
was the rule.** A skipped test reads as a pass in the summary line.

It now names `import_file_store` — found by walking the enclosing `def` above the `damage = []` it
builds — and the docstring says why it is named rather than discovered.

## The generated demo page, and why it is unchanged

`test_the_committed_page_is_the_one_the_agent_writes_today[recording.html]` went red, as it should:
the generator changed. Regenerating showed **four** pages modified — three of them only by line
endings, with `git diff --numstat` reporting `1 0` for `recording.html`. The one added line was
**two spaces**: the `__DAMAGE__` placeholder rendering empty on an undamaged store.

Committing a 436 KB regenerated artefact for two spaces is noise, and it teaches the next reader of
that diff that the page really changed. The placeholder now joins the end of the line above, so an
undamaged store produces a **byte-identical** page and the committed file needs no change at all.

**A generated artefact should not churn because a feature was added that its input does not
trigger.**

## Reservations

1. **Criterion 7's CSV comment row will be parsed as data by a strict reader.** That is the cost of
   putting a document-level fact into a format with nowhere to put one, and it is smaller than
   handing someone a clean-looking sheet cut from an interrupted write. Named in the record rather
   than discovered by whoever imports it.
2. **Criterion 6 makes `html` render `1234` as a timestamp** instead of raising. A wrong-looking
   timestamp shown honestly beside a banner saying the store is damaged is better than a traceback
   and better than a clean page — but it is a value that will look like a bug to someone who does
   not read the banner.
3. **Criterion 4's rule reads the importer's source with a regex.** A flag named through a variable
   or in a helper slips past it. Narrow on purpose, and the docstring says so.
4. **The export path had never been swept by any earlier round.** `html` and `playback` were hidden
   from `--help` until `CHG-20260903-32` a few hours ago, which is part of why they were the least
   exercised surface in the repository — and the defect seat found three defects there in one pass.
   **Nothing suggests it is now clean; it suggests it had never been looked at.**
