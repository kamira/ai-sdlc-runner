## The change broke something of its own, and the derivation caught it

`module_built --no--> next_module` opened a path **out** of the module loop.
`graph.module_cycle()` bounded on `record_module`, so the traversal escaped and began returning
`merge`, `pr`, `lead_review` — the set `engine._MODULE_CYCLE` uses to decide **which nodes run
inside a module's worktree**. The whole change's review would have run in one module's tree.

Bounded on `next_module` now, which is what the lap actually is.

CHG-20260827-21 wrote that function as a traversal on the argument that *"a hand-written list of
five node ids would leave a node added to the loop later quietly outside it"*. The failure this
time was the mirror image — a list would have gone on looking **correct** while the graph moved
underneath it — and the derivation surfaced it in the first check after the edit. It is pinned by
its own test and its own mutation.

## A default dispatcher that modelled a build reporting nothing

Five `test_flow.py` tests failed. They use `record_module` as *a node that has effects*, and have
nothing to do with the module loop — but `Recorder`'s default answer for `engineer_build` reported
no module, so every ordinary lap took the empty path.

Nothing had noticed, because nothing read it: those tests drive `next_module` from `DECISIONS`, so
the frontier never asked. The stub was wrong the whole time and only became visible when something
started reading the field.

Fixed at the default rather than in five tests: a builder says what it built.

## Reservations (disclosed, not waived)

1. **An empty lap is not free.** The engineer is still dispatched, self-verify and the review still
   run; only the recording is skipped. Whether the lap should be avoided entirely is a question
   about `next_module` and the frontier, and this change does not ask it.

2. **`record_module`'s effects are otherwise untouched.** This decides *whether* it runs. What its
   three effects do when they run is unexamined, and `weather-spa` is the only shipped example that
   declares any — so the effect path itself is still exercised by exactly one example.

3. **The five `test_flow.py` tests were repaired at the stub, not re-argued.** They intend "a normal
   lap in which everything passes", and a build reporting nothing was never that. Somebody who
   wrote them may have meant the empty case somewhere, and this change assumed not.

4. **Verified by the implementer**, on a design the operator chose. The choice between a branch and
   a conditional was not mine, which is the part of this that went right.
