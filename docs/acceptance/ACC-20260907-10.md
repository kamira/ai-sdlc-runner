### The reviewers refused the framing I gave them

I offered "this protects tests only; is that worth shipping". The answer came back with a citation
rather than an opinion: `policy.py:184-185` says the checks run *"including one whose graph a
caller has altered in memory"*. The rule guards a documented surface. Both reviewers reached
`validate` (not `Node.__post_init__`), a separate `if` (not a longer condition), and refusal (not
repair), independently.

### A claim of mine that did not survive

An earlier draft said the two `_validate_one` tests pass for a reason other than the one their
names claim. A reviewer measured both the half-swap and the full swap and the messages are
byte-identical. The claim is out of the record. The helper is still repaired — not because those
tests were wrong, but because the half-swap is the hazard `validate` now refuses.

### The mutations

```

```

The first exists only because a test was written to trip it. Once `_validate_one` swaps both
views, nothing else in the suite performs a half-swap — a rule installed to close a hazard, with
the last thing that exercised the hazard repaired in the same change, is a rule that would have
reported `NOT CAUGHT` on day one.
