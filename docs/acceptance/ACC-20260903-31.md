## Reservations

1. **`test_an_ordinary_status_line_is_unchanged` is a weaker negative control than it looks.** It
   goes red under the revert because `_porcelain_paths` does not exist there, not because the
   ordinary case parses differently. It is still the right assertion — the ordinary case must
   produce exactly the old list, and it does — but it does not, on its own, prove the fix left the
   common path alone. What proves that is the whole suite: `test_worktree_isolation.py`'s other
   thirty tests drive `uncommitted()` through real repositories and none of them moved.
2. **Both halves of a rename are now reported, which is a judgement rather than a measurement.** A
   build cut from a commit sees neither the old path (gone from the working tree) nor the new one
   (not yet in the commit), so both are things the operator would want to know — but an operator who
   reads the list as *"files I still need to commit"* will now see one more entry per rename than
   they expect. Stated because a seat may prefer the new path alone.
3. **The README guard now runs a walk, so it is slow and it couples to the flow.** A genuine change
   to the graph will move the number and turn this red, and the sentence will have to move with it.
   That is intended — the sentence is *about* the run — but it converts a regex check into a
   behavioural one, and a future record that finds that too heavy should replace it deliberately
   rather than reverting to a literal.
