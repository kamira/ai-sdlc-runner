### The mutations

```
CAUGHT  the scanner goes back to reading one separator
CAUGHT  normalisation replaces the raw haystack instead of joining it
CAUGHT  only the first spelling that matches is consulted
```

The second is the one that makes the design decision testable rather than merely explained. The
union exists so that normalisation can only *add* a stop; replacing the haystack is the shape that
would let a future rule containing a literal backslash stop matching silently. That revert is now a
caught mutation rather than a paragraph.

### The cost, measured rather than predicted

The record states that adding stops is not free and that a path ordinary yesterday can halt a run
today. The first full-suite run after the change answers how much of that is already realised in
this repository:

```

```

**No existing test changed its answer.** The three failures were the README count, the missing
acceptance (this file), and the record naming two tests that do not exist.

### One assertion removed before registration

The first draft of `test_reading_both_spellings_can_only_add_kinds` opened with

```python
assert set(policy.derive([probe])) >= set(), kind
```

which is true of every possible value, inside a test named for a guarantee. It was deleted rather
than left in. This is the shape the eleventh and twelfth rounds have spent their time on, and it
appeared here in the test written *for* the guarantee — which is the reason it is recorded rather
than quietly fixed.

## Scope, stated

`permanent_halt` is **not** changed. It reads prose, its word lists are multi-word English phrases,
and it was measured returning `None` for these targets in both spellings before and after. On
Windows there is therefore still no second line behind `derive` for a path target; making the prose
check a path reader is a different change with a different argument, and criterion 5 pins that it
was not made here.

The consequence the conformance seat found — that `attachments.py`'s three headline safety tests are
green against the design they defend, on Windows — is **not** closed by this change. Those tests now
have a scanner that can see their targets, but two of them still assert on `policy.derive` directly
rather than through `_spoken_halt`, and one neuters its own case with `.replace("/", "_")`.
`CHG-20260905-05` repairs the tests and the three records that quote them.

## Verdict

**Pass.** The scanner reads the separator this runner actually uses, by a construction that cannot
subtract a detection, with a floor under the agreement test and three caught mutations. The cost the
record warned about was measured and is currently zero inside this repository.
