## Two reported numbers were wrong, in opposite directions

`graph.Node`'s docstring is false for **seven** of the ten gated nodes. The conformance seat reported
six; the idiom seat reported eight. Measured: 10 gated, 3 `before` (`engineer_selfverify`, `pr`,
`merge`). The finding is sound in both reports; the count is mine.

## The correction ran into a derived guard, and the guard was half wrong

Setting `SCHEMAS.md` to `6 of 6` turned `test_the_page_says_which_tables_are_built_and_which_are_not`
red:

```
the page must say how many of the 7 tables exist; 6 do
```

The guard derives `designed` with `CREATE TABLE (\w+)` over the whole page. The real DDL form is
`CREATE TABLE IF NOT EXISTS <name>`, so when this record's annotation quoted `store.py` verbatim the
pattern captured **`IF`** as a seventh table.

**The guard is right about the property and was wrong about where to look**, and it is *derived*
rather than frozen — its own comment records an earlier version accepting a hard-coded *"three of
five"*, and that *"the frozen half made the computed half optional"*. That is precisely why it
caught this change. It now anchors to the start of a line: DDL is, prose about DDL is not.

**No seat found this.** It exists because a documentation fix ran into a computed check, which is
the argument for computing them.

## Reservations

1. **Two of the three paths criterion 4's rule first flagged were its own fault** — a test docstring
   quoting the old path (this record's own), and a directory fragment that is prose. Both were fixed
   by narrowing the rule, in the test, with the reason. **Neither was fixed by changing code to
   satisfy it**, which is the second time this session that distinction has had to be drawn.
2. **Criterion 3's rule compares keys, not types.** A key documented with the wrong shape still
   passes it; `"safety": […]` is caught here by an explicit assertion rather than by the rule, and a
   future wrong type would not be.
3. **`docs/API.md` is a contract for callers outside this repository.** Correcting it is right, and
   anyone who wrote against `{"<aspect>": …}` was writing against something that never matched — but
   the correction is still a change to a published shape.
4. **The guard fix is mine and unreviewed by any seat.** It loosens nothing — anchoring to a line
   start makes the pattern stricter — but it edits a check written by an earlier round, and the next
   review should look at it.
