## Reservations (disclosed, not waived)

1. **Written by the implementer**, on a defect somebody else measured — and on a claim this
   implementer made. CHG-20260901-07 said CHG-20260901-12 "is what makes that mean something" about
   the redraw loop. It was not, and the seat measured it.

2. **The appendix does not travel.** `_send_back` writes the verbatim objections beside the brief
   and marks them *"reference, not instruction"*, arguing that the words actually said should travel
   with the words that replaced them. The **instruction** now travels; the reference still lives
   only in the report. Carrying it too would make the order a rework with four masters, which is
   the reason that function split them — but the docstring's argument is about both, and only half
   of it is now true.

3. **Nothing is bounded.** Third time in three changes. Every existing loop bound in this flow is a
   graph edge; the loops without one still have none.

4. **A single-model run is unaffected.** `_send_back` fires only from the panel path
   (`len(configured) > 1`), so the shipped examples — which configure one model per node — see no
   change. The defect was real and the population it affects is the one that configures panels.

5. **Nothing checks the rework responded to it.** Same line as CHG-20260901-12: the brief is in the
   instructions and whether the next answer addresses it is a judgement about content.
