## Reservations (disclosed, not waived)

1. **Written by the implementer**, on defects somebody else measured. Fifteen for fifteen.

2. **This tightens sandboxes on runs that were passing.** A run whose panel raises the grade now
   dispatches at `{'write': 'none', 'network': False}` where it used to get the workspace. Work that
   succeeded will fail, and it will read as a regression before it reads as a fix.

3. **`_grade_in_force`'s per-workstream branch executes on a default install for the first time.**
   Its two tests build the report by hand (`tests/test_risk_adjudicated.py`,
   `tests/test_workstream_risk.py`); neither drove a walk to it. It is now reachable by every run,
   and its first real exercise is in production rather than in a test written for it.

4. **D-1's fix reads the grade off the work order.** That is minimal and provably the same value —
   but it makes the sandbox depend on `workorder.render` having put `policy_verdict` there. If a
   future order shape drops or renames that key the grade silently falls back to the bound one,
   which is the plan's proposal. The fallback is deliberate (a factory that offers no `grade` must
   still work) and it is the direction that fails *open*.

5. **The settling moved and I nearly moved it wrong.** The first version compared
   `choice == policy.PASS`, which `pm_signoff` never produces. It is in the CHG rather than only
   here because the wrong version would have passed a walk that never reaches `pm_signoff` and
   silently never settled — the same defect, relocated.

6. **D-3 has no fix of its own.** It is asserted to follow from D-2, and it does — but the closing
   turn is written by `conversations.close`, and nothing in this change tests the turn itself. If
   `close`'s falsy-drop is ever what a reader depends on, this is where that would surface.

7. **D-4 and D-5 are not fixed here.** `--worktree` is silently inert for a module built by a
   `node_models` model, and `plan.FIELDS`' drift guard is one-directional. Both are measured, both
   are real, and both are outside this change's root. Named so they are not lost.
