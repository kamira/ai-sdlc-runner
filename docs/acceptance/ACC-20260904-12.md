## Reservations

   is withdrawn and handed this forward`, and `Proposed by:` has no reader - `REQUIRED_FIELDS` is

   walked. So the edge exists in one direction and is invisible to every instrument, which is the
   asymmetry `CHG-20260828-02`, `-26`, `-30` and `-08` each closed one field further in. Named by
   the idiom seat and not fixed here: it is a ledger change, not a withdrawal.

   `policy.relax` still takes no node, so the entry can go stale silently the way the struck-through
   one did not. A guard would be a different change; the section's own warrant is that saying less
   and saying it truly beats a tool that overstates what it enforces.
