## Not closed by this record

**The target list is a floor, not a ceiling** — the CHG's own words, and still true. An operation
that names no targets, or names ones nothing matches, rests on the declaration; what changed is that
resting on it is now recorded as `on_trust` rather than passing silently.

Deriving targets from the work itself rather than from what the plan says it will touch would need
the runner to execute or statically analyse the step. That is a different system, the CHG says so,
and nothing since has built it.
