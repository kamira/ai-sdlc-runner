## Read this first

`engine.py` says, above the first of three `report.suspended = {...}` sites:

> *"Every kind of suspension carries the same keys, so a caller never has to know which shape it is
> holding before it can read one … each says so rather than omitting the field — **a missing key
> and a false one read the same way only until they do not**."*

Measured:

```
the three shapes          9 / 11 / 13 keys
shared by all three       9
only on a tie             reason · verdicts
only on an incomplete     missing · options · problems · safety
```

**Six fields are omitted, not said-so** — the thing the comment's own last clause warns about.

### And a caller believed it, yesterday

`CHG-20260904-02` added the terminal's third branch and read
`stop.get("reason", "nobody has finished it")`. The incomplete shape has no `reason`, so:

```
the terminal printed   nobody has finished it
what existed           The requirement does not say: the architecture — what the pieces are
                       and which one owns what (asked once). Nothing has been planned or built …
```

The sentence naming the aspect **and how many times it has been asked** never reached the terminal
— in the surface that record exists because nobody had swept it. I copied the tie branch's idiom
into a shape whose dict does not carry the key, and the comment is what made that look safe.

## The fix is the data, not the three surfaces

`_suspension(**said)` fills every field from `SUSPENSION_FIELDS` and **refuses a name no reader
expects** — a typo that adds a key nobody reads is the quiet half of the same defect. All three
sites call it.

And the incomplete shape now carries the sentence, because the sentence is computed **before** the
shape instead of eleven lines after it. That ordering was the whole reason the field could not be
filled, and the terminal reads `stop["reason"]` with no fallback.

## Task 7, and task 5 is what it found

```
a shape goes back to a dict literal      ##########  red
the shape stops carrying the sentence    ..........  SURVIVED -> ##########  red
an unknown field is passed through       ##########  red
```

The middle one survived the first time because the guard asserted the **key was present** — and
removing `reason=said` leaves the key with its empty default. Present is not enough: an empty
string is exactly what the terminal would print. The guard now asserts the sentence names the
aspect, names the count, and equals `report.halt_reason`.

That is the same distinction as CHG-20260904-02's own *"the word was in the output; the line was
not"*, one level down: the key was in the shape; the sentence was not.

## And an existing guard named its own retirement, correctly

`test_the_guard_over_the_suspension_section_reads_every_literal_there_is` — **removed in
CHG-20260904-07**, and replaced by `test_the_page_documents_every_field_a_suspension_can_carry`
— ended with:

```python
assert every - first_only, "reading only the first literal now misses nothing; drop this guard"
```

It existed **because** the three shapes disagreed. With one union there is no first literal and
nothing a second reading adds, so its own condition held and it is retired — replaced by the
stronger property, that the page documents every field `SUSPENSION_FIELDS` declares, plus a floor
asserting no shape is built as a dict literal.

Its helper’s docstring already recorded the defect: *"a guard named for enumerating every key a
suspension carries enumerated nine of fifteen — and passed, while the page it pins says ‘Every kind
of suspension carries the same keys’ directly above a list missing four."* **The guard was fixed
then and the engine was not**, for as long as that comment has been in the tree.
