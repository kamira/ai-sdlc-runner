## The seat's count was 17, and the measurement says 15

```
RunReport().as_dict() fields                     30
server RunState().snapshot() keys                19
report fields the console never NAMES            17
of those, whose content reaches it renamed        2
report fields reaching no console at all         15
```

`snapshot()` reads `report.halted_at` as `"at"` and `report.halt_reason` as `"reason"`. **A
name-based count flags both** — which is the class of error this whole round has been finding,
appearing inside one of the round's own findings. Taking the 17 at face value would have built this
record on a wrong number, exactly as `CHG-20260903-25` was built on a wrong address.

The fifteen, grouped by what they are:

```
the grade         risk_proposed · risk_settled · risk_agreed
the class         change_class · class_authorised_by · relaxations ·
                  relaxations_by_class · relaxation_authorisers
what it did       effects · halts · panel_rounds · resumed · single_model_panels
trust and store   on_trust · store_errors
```

**The console renders what the run is doing and nothing about what governed it** — no grade, no
relaxation, no permanent-halt list. `relaxations_by_class`' own comment is *"A relaxation nobody can
enumerate afterwards is a relaxation nobody can audit"*, and the surface an operator actually
watches enumerates none of them.

## The rule that was cited is honestly named; the citation was not

`test_every_key_the_server_sends_reaches_the_console` iterates `RunState().snapshot()`. Its **name
says so** — *the server sends* — and it does what it says.

`CHG-20260903-24` retired CHG-20260901-15 task 24 on the ground that *"the rule `-29` shipped means
the next field to go unrendered fails the suite rather than needing a task."* A report field that
never enters the snapshot cannot fail that rule. The rule watches 19 keys; the task was about 30
fields. **The record cited a guard for a scope the guard never claimed.**

That correction belongs to `-24`'s next draft. What belongs here is the gap the citation was
covering.

## What this change does, and what it deliberately does not

- **Does**: a rule over `RunReport().as_dict()` that requires every field to be either reached by
  the console or listed with a **stated reason**, so the fifteen are visible and the sixteenth
  fails.
- **Does not**: build fifteen console elements. That is a feature, it is CHG-20260901-15 task 24's
  actual scope, and inventing it inside a defect fix is how a record stops being one.

Disclosure replacing silence — the same disposition as CHG-20260903-47, where a paragraph denied
two consequences and now names them.

## Task 7 — and the first mutation was aimed at the wrong link

```
a field is emitted and nobody says where it goes   ██████████  red
the inventory loses an entry                       ██████████  red, both guards
the rule counts names instead of content           ██████████  red, both guards
```

The first was written as *"add a field to `RunReport`"* and **survived** — because `as_dict()`
builds a literal dict, so a new dataclass field never reaches it. That link is already held by
`test_the_report_emits_every_field_it_declares` (CHG-20260901-16). The link this rule owns is
*emitted and unaccounted*, and mutating **that** turns it red.

Recorded because a survived mutation is not automatically a gap: it is first a question about what
was mutated. The chain is `declared -> emitted -> rendered or written down`, and the two rules meet
at the join.

## A backspace, and why three tools could not see it

The rule's word boundaries went through a shell heredoc and came out as **byte 0x08** — not
deleted, *interpreted*. `re.search(r"<BS>adjudications<BS>", page)` matched nothing, so every field
looked unreachable and the guard flagged all thirty.

`Read` rendered the line as `r"%s"`. `sed` printed the same. An `Edit` anchored on what they showed
could not find the string, twice; a shell repair ate another escaping level and replaced the
backspace with a backspace. `cat -A` showed `r"^H%s^H"` in one line, and the fix was a byte-level
replace run from a **file** rather than from a quoted `-c`.

Written into the record rather than only into memory because it cost six exchanges, and because the
shape is this ledger's own subject: a thing that is there, invisible to the instrument being used to
look for it.

## Risk & rollback

- **No behaviour changes.** No route, no gate, no output moves. What changes is that a report field
  added tomorrow must be rendered or explained.
- **The list is a real cost.** Fifteen entries with reasons is a thing to maintain, and a reason
  written once and never revisited is how an exemption list rots. The rule requires a reason string,
  not its truth — stated rather than implied.
- Rollback: revert. The fifteen go back to being invisible and unwatched, and the next field joins
  them silently.
