## L-35 — the same sentence wrong for the third time

`sqlite3` in its default mode opens its implicit transaction before **DML only**. Measured on a bare
connection:

```
after CREATE TABLE   in_transaction: False
after PRAGMA         in_transaction: False
after INSERT         in_transaction: True
```

So `with _locked(db), db:` wrapping a body of `CREATE TABLE` plus `PRAGMA user_version` committed
nothing it had wrapped, and the half-built state **all three** migration blocks promise is
impossible was possible. With an explicit `BEGIN`:

```
after CREATE TABLE   in_transaction: True
after PRAGMA         in_transaction: True
a crash inside       tables: []      user_version: 0
```

**And this paragraph has now been wrong twice before.** Its own text records the previous
correction: *"which made the previous comment's claim of 'one transaction' false about the four
lines under it. A seat caught the contradiction."* That fix removed `executescript`; it did not
open a transaction. The comment then said *"the whole migration really is one transaction"* — the
third statement of the same claim, and the first true one is this.

`_verify_or_refuse` and `CREATE TABLE IF NOT EXISTS` still recover a half-built store, which is why
nothing was ever seen to break — and the same comment presents them as superseded by the
transaction it did not have.

## L-45 — the two formats that render the walk, hidden

```
conversations.FORMATS   ('json', 'markdown', 'csv', 'html', 'playback')   -> 5
cli.py                  help="export one conversation as JSON, Markdown or CSV"
cmd_export docstring    "the three are not interchangeable"
```

`html` and `playback` both work and are the **only two that render the walk**. The help is derived
from `FORMATS` now, so it cannot drift from the tuple again.

## L-38, L-39, L-40 — three declarations with nothing behind them

**L-38.** `ship.record_effects` quotes the flow — *"ticks, commits and updates the worklog — three
ordered effects"* — and adds *"until this existed that sentence was a comment on a node that did
nothing."* Measured: `['tick']` without an `acc_id`, `['tick', 'acceptance']` with one. **There is
no `commit` effect and no `worklog` effect.** The docstring now says so. Building them is real work
— what a `commit` effect probes for is a design question with an operator in it — and this record
does not do it.

**L-39.** `tui._curses_select_on` says it is *"the embeddable core reused by … callers — such as the
resident dashboard — that already own the curses screen."* One call site in `src/`: `_curses_select`,
directly below, which opens its own `curses.wrapper` — the exact thing the split says it lets a
caller avoid. `dashboard.py` **does not exist**; `test_ledger_check.py` records it as part of a
removed architecture. Kept rather than inlined, because the shape is still right; what is removed is
the claim that someone already uses it.

**L-40.** `Trees.report()` — *"What actually happened, for the run report — never what was
intended."* **Zero call sites** in `src/` or `tests/`; the run report's line comes from `describe()`.
And `made = len(self._trees)` reads a dict that `close()` empties, so after a run that made two
trees it fell through to `describe()`, which returns *"a worktree per module build"* — the design
sentence. **Deleted**, with the reason left where it was.

## Risk & rollback

- **Task 1 changes what happens on a crash mid-migration**, from a half-built store recovered by
  `IF NOT EXISTS` to no store at all. That is the intent — the paragraphs promise it — but it means
  a partially-written file is now rolled back rather than repaired, and an installation that had
  been quietly relying on the repair will see a clean retry instead.
- **Task 9 deletes a public-looking method.** It has no callers in this repository and appears in no
  document, but a downstream reader could have been using it. Named in the record rather than
  removed silently, and the comment left in its place says what it did and why it went.
- **Task 7 documents a gap rather than closing it.** `commit` and `worklog` remain unbuilt, so the
  flow's sentence is still a comment on work nothing does — one layer in from where it was. A seat
  may rule that this should have built them instead.
- Rollback: revert. The migrations claim a transaction they do not open, the refusal strands the
  operator again, and three declarations point at nothing again.
