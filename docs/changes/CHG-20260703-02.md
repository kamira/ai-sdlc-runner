## Motivation
When the runner drives real agents via the `command` backend (`claude -p`), those agents inherit the
host's full skill set. The user wants spawned agents to load **only ai-sdlc**. Rather than hardcoding
Claude-Code-specific skill-disabling flags into the runner (which would violate the platform-agnostic
principle — the contract targets the skill's stable output, not Claude Code's runtime), add a
**generic passthrough** so any restricting flags/env can be injected, and ship a ready-made
pure-ai-sdlc example for the `claude` CLI.

## Decisions & trade-offs
| Decision | Options | Assumptions | Why this choice |
|----------|---------|-------------|-----------------|
| Isolation mechanism | hardcode Claude-Code flags vs generic passthrough | runner is platform-agnostic (build-guide §1.7) | **Generic `extra_args` + `extra_env`** on `executor.command`; platform-specifics live in config, not code |
| Which backend | all vs command-only | skills are a CLI concept; api has no auto-skill-load; stub is a no-op | **command backend only**; api/stub unaffected (documented) |
| Ship an example | none vs pure-ai-sdlc settings | user wants "only ai-sdlc" out of the box | Ship `config/pure-ai-sdlc.settings.json` (disableBundledSkills + non-ai-sdlc plugins off) referenced by `--settings` |

## Modification Guide
### Goal
Let the `command` executor pass user-defined extra CLI args and env vars to the agent process, so a
`claude -p` agent can be constrained to only the ai-sdlc skill — without the runner depending on any
Claude Code runtime specifics.

### Impact scope
| Affected item | Type | Change | Knock-on |
|---------------|------|--------|----------|
| `src/ai_sdlc_runner/executors.py` | logical | `CommandExecutor` appends `extra_args` to argv and merges `extra_env` into the subprocess env | api/stub paths unchanged |
| `config/runner.yaml` | design | `executor.command.extra_args: []`, `executor.command.extra_env: {}` (documented, default empty = no behavior change) | opt-in |
| `config/pure-ai-sdlc.settings.json` (NEW) | design | example Claude Code settings: `disableBundledSkills: true` + non-ai-sdlc plugins disabled | referenced via `extra_args: ["--settings", "config/pure-ai-sdlc.settings.json"]` |
| `tests/test_executors.py` | logical | assert extra_args appended + extra_env merged for command backend; api/stub untouched | regression |
| `README.md` (EN + 繁中), `docs/ARCHITECTURE.md` (§6) | docs | document the passthrough + pure-ai-sdlc recipe | — |
| `docs/structure/logical.md`, `docs/structure/design.md` | logical/design | executor now supports extra_args/extra_env | truthful structure |
