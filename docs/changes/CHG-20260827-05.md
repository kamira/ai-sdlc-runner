## The finding

CHG-20260823-40's task 4 says the timestamp resolution is *"asserted both ways"*. Reverting
`_now()` (`conversations.py:1063`) to `timespec="seconds"` leaves 147 conversation, demo and
recording tests green.

`git show --stat 2661659` - that change's own commit - shows it touched **only
`tests/test_paths.py`** under `tests/`. No test for the clock was ever added. The forward direction
is guarded by nothing; the backward direction is exercised only incidentally, by a test about
duplicate `seq` that happens to load a second-resolution stamp.

## What changes

One test each way, both deliberate: a turn written now carries millisecond precision, and a stored
turn at second resolution still loads.
