## Scope: the second finding is larger than reported, and half of it is not fixed here

The defect seat reported that the console never reads `source`. Measured, **the console renders no
assignments at all** — zero occurrences of `node_models`, `seat_models` or `assignments` in
`console/index.html`. So:

- **The server half is a defect and is fixed.** The provenance is computed and was dropped; now it
  is threaded from `cmd_serve` through `serve` to `make_handler`, and `GET /config/nodes` answers
  it on a freshly started server.
- **The console half is a missing feature, not a broken one**, and building an assignments view is
  not a defect fix. `docs/API.md`'s sentence is about the API field, and the API is what is made
  honest here. **Named, not folded in.**

## One fact had five copies, and adding a field broke every one

Adding `reach_guessed` to `Model.as_dict()` turned two existing tests red — and fixing those
turned three more red, in cascade. **Counted at the end: five hand-written copies of “which
fields are computed and must never be stored”**, one of which asserted the literal source text
of another:

```
test_the_computed_reach_is_not_written_to_disk    "Storing it would let a file say `local`
                                                   about an endpoint that has since been edited."
test_a_round_trip_keeps_every_field
```

`as_dict()` is **persistence as well as wire**, and `save` excluded the computed fields with a
literal tuple:

```python
if k not in ("reach", "leaves_this_machine")     # both are computed
```

So a third computed field meant remembering a second place — **which is the shape this session has
been closing all day**. The fix is not a third string in that tuple: `models.COMPUTED` names them
once, `save` excludes whatever it names, and the test derives its assertion from it. **A fourth
computed field cannot reach disk by being forgotten.**

## The one fact had three copies, and adding a field broke all three

**That is a check on the spelling rather than on the property**, and it is the class this ledger

All three now derive from `models.COMPUTED`. **A fourth computed field changes one line.**

## Risk & rollback

- **Task 1 adds a field to `GET /models`.** A caller that enumerates keys strictly will see one
  more; the field is additive and no existing key changes.
- **Task 2 changes what an operator sees**: a guessed reach renders as `internal?` with a tooltip
  saying what it was inferred from and what it exempts. That is louder than before, deliberately.
- **Task 10's rule flagged its own docstring**, which had reproduced the five copies to explain
  them. The exemption that would have hidden it — skip the file the rule lives in — is the shape
  CHG-20260903-33 got wrong, so the prose was rewritten and the scope left whole. Fourth time
  this session a rule fired on prose about the thing rather than the thing; fourth time the
  answer was to narrow the rule, never to reword code to satisfy it.
- **Task 4's rule is derived from `COMPUTED`, which is itself hand-written.** A computed field
  that nobody adds to `COMPUTED` still reaches disk — task 5 catches the opposite mistake (a name
  in `COMPUTED` that `as_dict` does not produce), not this one. Stated rather than implied.
- **Task 6 changes an answer on a live HTTP route** from `{}` to the real map. Anything that
  treated `{}` as "no overrides" was reading a defect.
- Rollback: revert. A guessed grade renders as a fact, the exemption it buys is unaccompanied, and
  a freshly started console says it knows nothing about where its assignments came from.
