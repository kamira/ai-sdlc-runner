## The finding

CHG-20260823-05 moved the unspent-confirmation report into `_finish` (`engine.py:1064`) so that
**every** way a walk can end reports it - its own record says *"a report that is only correct when
the run succeeds is not a report."*

Regressing `_finish` to emit the report only when `halted_at == "done"` - exactly the pre-fix
behaviour - leaves the suite green. The one behavioural test ends at `done`, the single exit that
always worked. The halt and suspend exits are covered only by source-text assertions that `_finish`
is *called*, not that its report survives the path.

## What changes

Behavioural tests for the exits that were broken: a run that **halts** at a gate and a run that
**suspends**, each carrying a confirmation the walk never reached, must report it.
