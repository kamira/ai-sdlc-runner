## Motivation
The resident dashboard's input box cannot accept Chinese (or any non-ASCII) text. Root cause:
`dashboard.run_resident` reads keystrokes with `stdscr.getch()` (one **byte** at a time) and appends
`chr(key)` only for `0 <= key < 256`. A CJK character is multiple UTF-8 bytes; each byte becomes a
stray Latin-1 char, so multi-byte input is dropped/garbled. Input must be language-agnostic.

## Decisions & trade-offs
| Decision | Options | Assumptions | Why this choice |
|----------|---------|-------------|-----------------|
| Read Unicode input | `get_wch()` vs manual UTF-8 byte accumulation | ncurses supports wide input when the locale is set | **`stdscr.get_wch()`** (returns a full `str` for typed chars incl. CJK, or an `int` for special keys) + `locale.setlocale(LC_ALL, "")` at startup. Standard, minimal, no hand-rolled decoder. |
| Testability | test the curses loop vs a pure helper | curses needs a real TTY | Extract a pure `apply_key(buf, ch)` that classifies a `get_wch` result (str char / Enter / Backspace / other) and returns the new buffer + an action; unit-test it with **CJK strings**. |

## Modification Guide
### Goal
Make the resident input box accept any language (UTF-8, incl. CJK), keeping Enter/Backspace/F2/arrow
handling intact, with a headless-testable core.

### Impact scope
| Affected item | Type | Change | Knock-on |
|---------------|------|--------|----------|
| `src/ai_sdlc_runner/dashboard.py` | logical | `run_resident`: set locale once; read via `get_wch()`; route `str` results through a new pure `apply_key(buf, ch)` (append printable incl. CJK; handle Enter/Backspace as str too since `get_wch` may return `"\n"`/`"\x7f"`); keep `int` special-key branches (F2, KEY_ENTER, KEY_BACKSPACE). Degrade gracefully if `get_wch` raises. | input only |
| `tests/test_dashboard.py` | logical | `apply_key` tests: ASCII, **CJK (你好)**, mixed, Enter, Backspace-on-empty/non-empty, ignore control chars. | regression |
| `README.md` / `docs/ARCHITECTURE.md` | docs | one line noting the input accepts any language | — |
| `docs/structure/logical.md` | logical | note UTF-8/wide-char input | truthful structure |

### Modification steps (tick when done)
- [x] 1. Add a pure `apply_key(buf: str, ch) -> tuple[str, str]` (or similar): `ch` is a `str` (from `get_wch`) → classify Enter (`\n`/`\r`) / Backspace (`\x7f`/`\x08`) / printable (append, incl. CJK) / ignore other control; return `(new_buf, action)` where action ∈ {"submit","edit","noop"}.
- [x] 2. `run_resident`: `import locale; locale.setlocale(locale.LC_ALL, "")` before `curses.wrapper`; in the loop read `ch = stdscr.get_wch()` (wrap in try/except `curses.error` → continue). If `isinstance(ch, int)`: keep the existing special-key branches (F2, KEY_ENTER=submit, KEY_BACKSPACE=edit). If `isinstance(ch, str)`: route through `apply_key` (submit on Enter, edit on Backspace/printable). Remove the old `0 <= key < 256: buf += chr(key)` byte path.
- [x] 3. Tests per step 1 (CJK included). Full suite green.
- [x] 4. Docs: README/ARCHITECTURE one-liner + structure/logical note.
