## Interpreted, and what it was chosen over

- **Three dimensions ship off** (錯誤處理/可觀測性, 相依/供應鏈, 國際化/在地化). The user asked for as many
  as possible and for the choice to be theirs; shipping them on spends quota on a choice the user
  did not make. Chosen over all-on.
- **Cross-read is per dimension.** Each engine reads the other engines' answers on the same
  dimension only. Chosen over reading all 36, which would carry every dimension's framing into every
  seat.
- **A dimension that does not apply still opens its session** and says so. Chosen over the
  orchestrator skipping it, which would be deciding what applies — the choice the user kept.
- **A cross-read DISAGREE does not by itself fail the round**; it is listed in both reports and
  printed, for the user to decide (escalated, not averaged). A seat that thinks a disagreement
  blocks says `VERDICT: fail`. Chosen over any DISAGREE failing the round, which would turn a
  difference of reasoning into a veto held by whichever seat disagrees.
- **`--out` inside the repo is refused**: raw seat output there would dirty the tree and fail the
  closing freeze check every time.
- **The coder rule is recorded, not enforced by the tool.** `coder` in `config/panel.json` is
  validated and documented; nothing can check which model wrote a diff.
