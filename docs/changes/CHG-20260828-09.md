# CHG-20260828-09 — a run that hit a red line recorded the word "stopped" and nothing else

- Project: ai-sdlc-runner
- Branch: claude/chg-20260828-09-closing-record
- Date: 2026-08-28 (UTC+0)
- Type: the durable record gains the thing it was missing
- Proposed by: two reservations, checked — ACC-20260827-19 #4 and ACC-20260827-17 #5
- Risk: **medium** — it changes what a stored conversation contains. Nothing about a run's
  behaviour changes.
- Autonomy: high
- Related: CHG-20260827-19 (halt routing), CHG-20260827-17 (the adjudicated grade),
  CHG-20260828-08 (reservations, and keeping them true)

## The gap, which is larger than either reservation said

Two acceptances disclosed halves of this:

> `ACC-20260827-19` #4 — *"Task 6 says 'appears in the export'. It appears in `report.halts` and in
> the `run` output. The conversation export was not extended, so a halt's recipient is in the run
> report and not in `--format markdown`."*
>
> `ACC-20260827-17` #5 — *"The grade appears in the report, not in the conversation export."*

Checking them found something bigger. A run stopped by a **permanent halt** — a `deploy`, the
reddest line this runner has — produced a conversation of:

```
opened · ask ×3 · answer ×3 · closed: stopped
```

**Nothing about the halt, the rule it broke, or who it is for.** All of that was in the run report,
which is stdout, and gone when the terminal is.

The conversation is the durable artefact — the thing an auditor is handed. A governance record that
keeps every question and loses the reason the run stopped has kept the least important half.

## The fix

`close()` takes `at_node`, `why`, `risk` and `change_class`, and `_finish` passes what the report
already holds. The closing turn now reads:

```json
{ "at_node": "pm_plan",
  "state": "stopped",
  "why": "permanent halt at 'pm_plan': 'ship it' is production deploy or release. No risk grade,
          confirmation, mode or change class relaxes this — a person does it. This one is for
          release, and the operator." }
```

An absent field writes no key, so a run with nothing to add produces exactly the bytes it did
before.

## `at_node`, not `at` — the guard that caught it

The first draft used `at`. That is the turn's **own timestamp**, and `Turn.as_dict` refuses a body
that names an envelope key: *"a body that can rewrite its envelope makes seq, kind and at unreliable
for every reader."*

The closing turn vanished from the record entirely — and the guard said so **loudly**, on stdout,
rather than dropping it quietly. That guard was added by an independent seat reading that one line,
and `DECISION` had already settled the name with `at_node`.

It is pinned by a test now, because `at` is the more natural word and the next person will reach for
it too.

## Risk & rollback

- No run behaves differently: the same gates fire, the same halts stop it.
- Stored conversations written before this are unaffected — they have none of the new keys and
  render exactly as they did.
- Rollback: revert. The export returns to saying `stopped` and nothing else.
