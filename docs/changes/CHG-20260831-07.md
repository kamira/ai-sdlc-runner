## The guard that turned a traceback into an overwrite

The worst finding, and it is the previous round's *fix*. CHG-20260831-06 added:

```python
if not isinstance(pid, int) or isinstance(pid, bool):
    return False
```

with a comment saying *"Treated as **not alive**, which is the safe direction here: an unowned
record is refused, not recovered over."* That sentence is backwards. `_alive` returning `False` is
precisely what lets `recover()` **act**. Measured, on a record with `"owner": "nope"` over a
mutated victim:

```
said : restored target.py, which a killed run left mutated
file : 'ORIGINAL SOURCE\n'     ← overwritten
record still there: False      ← deleted
```

Before the fix it raised `ctypes.ArgumentError` and left both alone. A guard written to stop a
traceback turned it into a silent overwrite plus a record deletion, under a comment telling the
next reader the opposite. Three seats found it.

The owner's type is checked in the record's shape gate now, where cannot-tell is refused.

## Veto: the rows added to pin a rule pinned nothing, and replaced rows that did

Task 5 of the last round widened `_PARAGRAPH_BREAK` and added three rows for it. Measured: with
`_PARAGRAPH_BREAK` replaced by a regex that never matches, **all 21 rows stayed green**. The
fixtures ended in a full stop, so the *sentence* bound refused them first. At the base commit the
same experiment failed **2** rows.

Coverage went from 2 to 0 in the round whose task was to strengthen it, and both records read as if
it had gone up. Six rows carry it now, none of them containing a sentence end.

And the cause the record credited was wrong. The risk seat measured what actually mattered: **every
record in this repository is CRLF**, so the old `\n[ \t]*\n` matched no paragraph break in any of
them. The bound the round-11 acceptance claimed simply was not there.

## The excusal rule refused six phrasings a person writes

Every one measured by a seat, and three of them are phrasings this repository's own comments
recommend:

| input | was | is |
|---|---|---|
| `Removed in CHG-X: …` — a capital at a sentence start | **refused** | accepted |
| `renamed to the new name in CHG-X` — what the comment tells people to write | **refused** | accepted |
| `…, i.e. the halt case, was removed in CHG-X` | **refused** | accepted |
| `-- gone! --`, `-- did anyone read it? --`, `... was removed` | **refused** | accepted |
| `[CHG-X][1]` — a reference-style link | **refused** | accepted |
| a break carrying U+200B or a byte-order mark | **excused** | refused |

The verbs are case-insensitive. A sentence end is punctuation followed by whitespace and a capital,
not any `.!?` — excluding them outright made `i.e.` a sentence boundary. And the **href claim is
withdrawn**: `linked in href` was a substring test that let `(../nowhere/CHG-20260901-01.md)`
through while refusing three link forms people write. Resolving a path needs a repo root
`_excused` does not have, so the claim is dropped rather than half-kept.

The per-offset scan is gone too: it cost **149×** on a 69 KB record. The scan starts where a match
can start — 2.24s → 0.02s, with the guarantee it was added for intact.
