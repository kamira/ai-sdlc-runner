## Rendered by the shipped exporter, not by a copy of it

```python
return conv.export_conversation(document, "playback")
```

The page is a demonstration **of the feature**, so it goes through `conversations.py` rather than
through anything local to `examples/demo/`. If `--format playback` breaks, this page breaks with it;
a private renderer would have kept working and said nothing. A test reads that call out of the
syntax tree.

## Replayed from a committed fixture, and why

Every other demo page is regenerated on each build and byte-compared. A recording cannot be: it
carries **wall-clock timestamps**, so a page rebuilt from a fresh run differs from the committed one
every single time, and the comparison that protects the other pages would have to be dropped for
this one.

So the run happens once, into [`examples/demo/conversations/`](../../examples/demo/conversations/),
and the page is rendered from that. The fixture is what a real console-driven run actually wrote —
`make_fixture.py` drives `runner serve` through the same routes the page uses:

1. the brief, typed and started
2. `merge` — the run stops, and a person approves it
3. a second instruction, added to the brief

That keeps both properties: the recording is real, and the page is reproducible.

## Absolute paths are scrubbed

The `opened` turn records the journal directory the run happened in. Nobody needs a stranger's temp
path in their repository, so `make_fixture.py` replaces it with `<journal>` — and refuses to write a
fixture if one survives. A test checks the committed fixture for the same thing, so a refresh cannot
quietly reintroduce one.

The pattern has to match a Windows path **as it appears inside a JSON string**, where every
separator is doubled. Matching the on-disk spelling would have missed every one of them.

### Not claimed

**That the fixture will stay current.** It is a snapshot, refreshed by hand with `make_fixture.py`.
What the suite guarantees is that the *page* matches the *fixture*, not that the fixture matches
today's runner. A change to the conversation schema would need the fixture regenerated, and nothing
here detects that on its own.

**That 320 KB is small.** It is most of this directory. The ceiling test exists because the honest
answer is "acceptable, and worth watching".
