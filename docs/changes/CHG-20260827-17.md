## The gap

`graph.py:150` — `lead_assess`, the node that grades feasibility and risk, is `mode=SINGLE`.

Every other consequential decision in the flow is adjudicated: `pm_confirm`, `pm_signoff`,
`lead_task_review`, `re_review` and `qa_accept` are `MODEL_PANEL`; `lead_review` is a `SEAT_PANEL`.
The one input that decides **which row of the gate table every later node reads** is the one input
no panel sees.

## It shields its own mistake

> Line numbers checked against `origin/main` at `7e9c276`. CHG-20260823-51 moved them after this record was written; each is quoted by its own text as well as its line, so the next shift is visible instead of silently pointing somewhere plausible.

`engine.py:1319` — `verdict = resolve_verdict(node, cfg.risk, cfg.autonomy)` — resolves every gate from the same `cfg.risk`. So a change graded `low` when it is
in fact a migration gets `before_dispatch: low → auto` — and the gate that exists to put a person in
front of exactly that change never fires.

The circularity is tighter than it first looks. `pm_signoff` is the panel that reviews the lead's
assessment, and `pm_signoff`'s own gate is resolved **from the grade under review**. The reviewer
stands at a height the reviewed thing chose.

## What this change does not do

It does not remove the operator's `--risk` override, and it does not touch the `high` default
(`engine.py:377`) or `--undeclared refuse`. Those three are the defences that make the current shape
survivable and they stay.

## Task 1 could not be built as written

`adjudicate(voices="models")` **cannot grade.** It counts how many voices said `pass` and returns
pass / undecided / fail — it is binary, and a grade is one of three. Asking it for `"medium"` returns
a count of passes.

`policy.adjudicate_grade` does the job and its docstring says why it is not the other one. The rest
of this record stands as written.

## An existing invariant refused the first attempt, and was right

`graph.validate` refuses `MODEL_PANEL` on anything but a `DECISION` — *"a node that reaches no
verdict has nothing to adjudicate"*. The rule it really enforces is that a panel must adjudicate
**something**: a `DECISION` reaches a branch, `lead_assess` reaches a grade. Widened by exactly that
case. A work-producing step with several models is still refused, which is what `POOL` is for.
