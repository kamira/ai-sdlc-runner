## 1. Three records call a test proof of something it does not test

`ACC-20260823-11` row 17, `CHG-20260823-11` task 17, and the test's own docstring all say
`test_both_directions_of_the_scan_survive` *"fails for either wrong answer."* Measured, with the
exemption the module docstring calls *"worse than the bug"*:

```
mutant: engine._TARGET_FIELDS = ("expected_outputs", "workdir")

pytest tests/test_attachments.py     -> 31 passed
pytest tests/test_false_stops.py     -> FAILED
```

The property **is** guarded — by `test_false_stops.py::test_the_paths_a_brief_names_are_read_as_
targets[input_artifacts-value1]`. It is not guarded by the test the three records name. Half 2 of
that test is:

```python
assert "deploy" in policy.derive(["kubectl apply -f prod/"])
```

a hard-coded string that never reaches `_spoken_halt` or `_TARGET_FIELDS`.

**Repair:** half 2 drives a real `RunConfig` through `engine._spoken_halt`, so the sentence becomes
true and the three records that quote it become true with it.

## 2. One parameter of the filename test trips nothing, on either platform

```
production.md        derive -> ('deploy',)
prod.md              derive -> ('deploy',)
deploy-to-prod.md    derive -> ()            <- trips nothing, before or after CHG-20260905-03
prod spec.pdf        derive -> ('deploy',)
PRODUCTION.PDF       derive -> ('deploy',)
```

Measured **after** the separator fix, so this is not the Windows blindness: `deploy-to-prod` has no
`/` or boundary character around `prod`, and the rule requires one. A parameter that names nothing
the scanner reads is a case that cannot fail, sitting in a list of cases that can.

**Repair:** replace it with a filename that is a red line for a *different* kind, so the list stops
being one rule five times.

## 3. The sentence the whole design rests on is false

`attachments.py:19`:

> The stored path is `<store>/<sha256>` - no extension, no operator-chosen segment, nothing a
> scanner can mistake for a deployment target.

The **leaf** carries nothing an operator typed. The **directory** carries everything they typed, and
`order_paths` returns the whole path:

```
--attachments 'attachments'        derive=()            no halt
--attachments 'spec prod files'    derive=('deploy',)   permanent halt on every node
--attachments 'billing/att'        derive=('money',)    permanent halt on every node
```

`CHG-20260905-04` added the startup refusal that makes the consequence unreachable. The sentence is
still false and is corrected here.

## 7. Two documents disagree about the module inventory, and the seat was wrong about which is right

documents against `src/*.py`.
