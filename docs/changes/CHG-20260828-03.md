## The gap

CHG-20260827-20 task 4 says the class is recorded *"in the report and the export"*. The report was
checked on every run; the export was not, and the acceptance said so as a reservation rather than
claiming it.

Checking it: the export **does** carry the class. It carries it as the runner's act.

```
<article class="turn runner"><span class="who">runner</span><span class="verb">relaxed</span>
  change class 'standard' declared by alex@example.com, due for review on 2026-12-31
```

`RELAXATION` covers two different things and `_VOICES` mapped the **kind**:

| act | who really did it |
|---|---|
| `--store-remote allow` | the runner, recording its own configuration |
| a change class | **a person**, pre-authorising a type of change |

The summary text names the person, so no information is lost. But the voice column — the thing an
export exists to make scannable — said the machine did it.

This repository's first claim is that governance is a person's judgement and never a model's. A
document that attributes an operator's judgement to the runner is wrong in the one dimension it
exists to keep straight, and wrong **in the direction that flatters the machine**.

## The rule

A relaxation naming `by` was done by that person. Everything else keeps the voice its kind implies.

Reading the turn rather than renaming the kind matters: one of the two acts really *is* the
runner's, and calling both `operator` would be the same error pointing the other way. An absent or
empty `by` writes no key, so a stored conversation is byte-identical to one written before this —
nothing already on disk is reinterpreted.

## Why the test asserts on the rendered page

The defect was never in `_VOICES`. It was that **two** renderers each read
`_VOICES.get(turn["kind"])` directly, so a test of a resolver would have passed against the broken
code — there was no resolver to test. The end-to-end case runs the CLI, stores a conversation, and
reads the `who` out of the rendered HTML.

## Risk & rollback

- No behaviour of a run changes: the same gates fire, the same class relaxes the same verdicts.
- Existing stored conversations are unaffected — they have no `by`, so they render exactly as
  before.
- Rollback: revert. The `by` key is additive and ignored by anything that does not look for it.
