## L-27, first half — six keys, measured

`RunState.snapshot()` returns 19 keys. Six of them match nothing anywhere in
`src/ai_sdlc_runner/console/`:

```
confirmations   what the operator approved
rulings         what was ruled
rejections      what was refused
survey          what the survey found
send_backs      what was sent back, and why
adjudications   every panel outcome, with the voices that made it
```

Between them that is **the whole record of what the run decided and why**. The server computes all
six on every poll and ships them to the browser; the page renders none of them. A person watching a
run sees where it is and cannot see what it has decided.

Added as `drawDecisions()`, in the file's own idiom — a `drawX()` per section, `textContent` for
every value because these strings carry model output and a seat's own words. The adjudication line
reads `grade` **or** `outcome`, whichever the adjudicator actually wrote: enumerating a shared
subset is what `CHG-20260901-18` was filed for, and a graded panel returns `grade` while a binary
one returns `outcome`.

Rendered and checked in a browser against a fabricated state, not just parsed:

```
APPROVED      plan_confirmed = halt at risk high at pm_confirm, confirmed by the operator
RULED         lead_assess graded medium
REFUSED       merge at merge was refused by the operator: not yet
SENT BACK     lead_review -> rework: the veto held
ADJUDICATED   lead_review -> fail (conformance holds a veto and did not pass) [conformance, defect, risk]
              lead_assess -> medium [a, b, c]
SURVEYED      answered: 3 · skipped: 1
```

## L-27, second half — **this does not reproduce, and the record says so**

The claim was *"`RunState.error` is never cleared on a successful walk, so a finished run shows the
previous walk's error box."* `self.state.error` is indeed assigned at exactly one place
(`server.py:510`) and nowhere reset — but the state machine already closes both routes:

```
error, then start() again      -> start() builds a fresh RunState:  state=finished  error=''
error, then approve()          -> ServerError: "this run is stopped; there is nothing waiting
                                   for an answer."
```

**No fix is shipped for it**, and the finding is recorded here rather than left as a live entry
somebody re-derives later. The first half of L-27 was real and is fixed; the second half was not.

## L-41 — a CSS selector written into a class attribute

```
line 136   class="ask .row"          two tokens: `ask` and `.row`
line  74   .ask .row{display:flex}   a DESCENDANT selector — needs a `.row` inside an `.ask`
           selecting the literal token needs `.\.row`, which the file contained 0 times
line  71   .ask{border:1px solid var(--wait)}   <- this is what applied
```

`--wait` is the amber the stylesheet reserves for *"the run is waiting for you"*. So the start /
add-to-brief / attach controls were permanently dressed as a pending question, never got their flex
row, and at a real gate the page showed **two** amber cards, one of which was not an ask.

The rule was the only user of `.ask .row` and its one intended element is a *sibling* of the ask
card, not a child of one — so the selector was dead in both directions. It is now `.row`,
standalone, which still applies inside an `.ask` if anything ever wants it there.

**A CSS selector in a class attribute is silent in every direction**: no parse error, no console
warning, and a page that looks plausible.

## Risk & rollback

- **The console gains a section that can be long.** A run with many adjudications prints one line
  each; nothing paginates. That is the honest trade against showing none of it, and it is the shape
  the log section already has.
- **Task 1's test will fail the next time a snapshot key is added** without a console line. That is
  intended and is the whole point of a rule over a list — but it means adding a field to
  `RunState.snapshot()` now carries a console obligation, which is a real cost.
- **`.dec` is new CSS in a file with no other stylesheet.** It uses only variables the file already
  defines in both light and dark blocks.
- Rollback: revert. The six keys go back to reaching nothing and the start controls go back to
  looking like a question.
