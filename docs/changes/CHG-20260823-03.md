## What the verifier found

`codex-seat`'s round-3 session was cut short by its provider's content filter before it produced a
verdict, so **there is no round-3 codex verdict** and nothing here claims one. What it did produce
before stopping is reproducible and is the whole of this change:

```
does_work= True
halt= None
relaxations= ['record_module ran undeclared: nothing was checked against the permanent halts']
side_effect= ['EXECUTED']
```

It built a run with `undeclared="allow"` and a real effect attached, and the effect **applied**, with
nothing checked against the permanent halts. The flag is documented "for a dry run". A dry run
changes nothing. The relaxation covered exactly the case it was written to exclude — and a
relaxation whose name says otherwise is worse than no relaxation, because it reads as safe.

It also wrote six new red-line sentences, none of which the backstop word lists catch. Those are
covered by the disclosed limit rather than being new defects: declared, all six stop. They are
folded into the corpus below because they measure something worth knowing.
