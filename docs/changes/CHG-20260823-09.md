## Why these two, now

CHG-20260823-08's Status named two things it had not done. Carrying a disclosed item is honest once;
carrying it twice is how a "known limitation" becomes permanent. Both are closed here.

## 1. A panel that is secretly one model

> 多模型互審:機制存在但純選配——不給 `--seat-model` 時三席是同一個 command 答三次
> (session 獨立、模型不獨立),沒有任何提示或紀錄說明本次面板是單模型。 — `fable-seat`

The requirement asks for cross-model review and gives its reason: one model cannot be relied on to
see its own blind spots. `--seat-model` makes it possible, and it works. But when nobody passes it,
three seats are one backend answering three times — **independent of each other's context, and not
of that model's blind spots**, which is most of what the seats were bought for.

Running that way is a legitimate choice; it is the default and it costs nothing. Running that way
while the report reads exactly like a cross-model panel is the false assurance this design exists
against.

So the run says so. `RunReport.single_model_panels` records any panel where every seat was answered
by the same backend, the CLI prints it as `single model:`, and the note names the fix
(`--seat-model SEAT=COMMAND`). **A disclosure, not a gate** — refusing to run would make the honest
default unusable, and the requirement puts the seat count in the user's hands.

Two judgements worth stating:

- **Partial overlap is not flagged.** Two of three seats sharing a model is a judgement the runner
  does not have the standing to make, and crying wolf would train people past the line that matters.
- **A one-seat panel is not called "single model."** The floor bypass is already recorded; two names
  for one fact is noise.

## 2. `--no-high-risk-mode` shipped without a test — and was wrong

`fable-seat` verified it by hand and found the behaviour correct. Writing the test found it was not:
declining the bypass left a below-floor seat count in place, so the run went straight into the
interactive confirmation the operator had just declined on the command line. **A flag that reopens
the question it answers.**

Declining now means *run at the floor*, and says so rather than silently raising the count.

The lesson is the small one this repo keeps relearning: a behaviour verified by hand is verified for
the path somebody thought to try. The test tried the path where the flag has to actually decide
something.
