## 1 · The exchange now carries its times

The replay always had the **order** — it is a timeline — but a card showed `#seq` and nothing else.
The wall clock lived only on the rail, once per stop. So you could see that an instruction preceded
an answer without seeing when either happened, or how long the model took.

Every card now carries the real time and the gap since the turn before it:

```
22:55:23  runner    opened
22:55:23  operator  instructed  +190ms  做一個當地一週氣象的單頁網站…
22:55:23  runner    asked       +30ms   seat · conformance
22:55:23  model     answered    +100ms  nothing missing, problems, unsafe
```

176 of the demo fixture's 306 turns show a gap.

### The store had to change for that to mean anything

`_now()` used `timespec="seconds"`, and at that resolution **18 turns of a real run shared one
timestamp**. The order survived — `seq` is the ordering and always was — but the timing did not.

Now milliseconds: worst case in the regenerated fixture is **2 turns per timestamp**, down from 18.
Reading is unaffected, and a test asserts it: `fromisoformat` parses both spellings, so
conversations already stored at second resolution still load.

## 2 · The audit was a blanket ban, and is now an allowlist with reasons

CHG-38 replaced *"every file write goes through it"* — an over-broad **claim** — with *"no module
may write directly, ever"* — an over-broad **rule**. The operator named it:

> paths 是根據流程走的，不一定每個節點都會遇到

Which writes can reach a deep path depends on the flow that runs, not on the module the call sits
in. A rule banning all of them would refuse a legitimate write to a temp directory on a path no
flow can make deep.

So the audit asserts a direct write is **accounted for**, not that it is forbidden: either it goes
through `paths`, or it appears in `ALLOWED_DIRECT_WRITES` with a reason. The allowlist is currently
empty — every write in `src/` is routed — and adding an entry costs a sentence, which is the point.

Two tests guard the guard: every exemption must carry a usable reason, and the audit is run against
a module that definitely bypasses (the test file itself) and asserted to notice — otherwise deleting
a call shape from its list would retire the check while leaving it green.

## 3 · Method: Python files, not shell heredocs

> 能不能不直接使用程式解而不是cmd或bash，如果硬要採取ps, sh解那麼就要依系統區分

Adopted for this change and onward. Every edit here was made by a Python script run as a file.

It is not a style preference: shell heredocs ate backslashes and em-dashes **six times** in this
session, twice producing a test that contradicted itself one line later while the code under test
was correct throughout.

### And the OS split, where shell-level behaviour actually differs

`examples/demo/make_fixture.py` crashed on Windows after doing all of its work:

```
PermissionError: [WinError 32] the file is in use by another process:
    ...\run\.runner\config.sqlite-wal
```

`proc.terminate()` asks; it does not wait. On POSIX an open handle does not block removal, so
nothing noticed — the generator was written and run on Windows and failed only there.

Both halves are now explicit: the **wait** is unconditional, because waiting for a process you
stopped is correct everywhere; the **retry** for a file the OS has not finished releasing is
`os.name == "nt"` only, and says so.

## Status


Accepted (see docs/acceptance/ACC-20260823-40.md) -- Pass with a reservation both engines reached independently: no test asserts the millisecond precision. Reverting the clock leaves the suite green.

### Not claimed

**That milliseconds are the true resolution of anything.** They are enough to order a fast run and
they stop short of pretending to more precision than the surrounding I/O has. Two turns still share
a stamp in the regenerated fixture.

**That the allowlist is exercised.** It is empty. Its value is the next direct write somebody adds —
and an empty allowlist has never had to refuse anything, so the mechanism is untested by use.

**That a gap is the model's thinking time.** It is wall-clock between two stored turns, which
includes process start-up, the runner's own work, and whatever else the machine was doing.
