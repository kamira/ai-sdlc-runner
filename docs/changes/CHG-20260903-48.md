## Read this first

```
policy.adjudicate_grade({m1: high, m2: high})  ->  outcome=pass   grade=high
policy.adjudicate_grade({m1: low,  m2: low })  ->  outcome=pass   grade=low

cli.py     print(f"panel: {decision['node_id']} → {decision['outcome']} ...")   both print `pass`
console    var said = a.grade || a.outcome || "?";                            prints high / low
```

**A run whose panel graded the change `high` and one whose panel graded it `low` produced
byte-identical terminal output.** `adjudicate_grade` returns `outcome="pass"` for every grade it
settles, so `outcome` alone carries none of the information the panel exists to produce.

And the settled grade itself reached no terminal line at all: `cli.py` named `risk_agreed`,
`risk_settled` and `risk_proposed` **zero times**.

## Why no test caught it

The two tests pinning that footer line both use `lead_review` — a **seat** panel, whose
adjudication carries no `grade` — so they were green either way. A guard over a shape the defect
cannot reach is not a guard against it, which is recorded here as a measurement rather than a
lesson: `policy.adjudicate({...})` is asserted to have no `grade` key, so if that ever changes the
note is revisited rather than quietly wrong.

```

the settled grade goes back to nowhere   ░░░░░░░░░░  SURVIVED → ██████████  red
```

The third guard asserted `"risk_settled" in inspect.getsource(cli)`. Replacing the guarding `if`
with `if False` left it **green** — the string was still there and could never be reached.

**Written ten minutes after `ACC-20260903-47` recorded the fourth instance of exactly that trap.**
Knowing the pattern is not the same as not falling into it; running the mutation is. The guard now
reads the **condition**: the line must be guarded by a test that mentions the value it reports, so a
constant condition fails.

A behavioural version would need a grading panel driven through the CLI with a model registry. That
is stated rather than pretended: this is the weaker check, and it is honest about being one.

## Risk & rollback

- **A terminal line changes**, and a new one appears when a panel settles a grade other than the one
  asked for. Anything parsing `panel:` lines for the literal `pass` will see the grade instead —
  which is the defect being fixed, not a regression.
- **No behaviour changes.** `policy`, `engine` and the console are untouched.
- Rollback: revert. A run graded `high` and a run graded `low` print the same line again.
