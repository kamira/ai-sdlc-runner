## What happened

Seventh round, four seats, four worktrees. **31 findings** — conformance 11, defect 3, risk 9,
idiom 8. Every seat failed it. Two vetoes.

## Veto 1: "both are pinned" was not

CHG-20260831-01 made the in-flight guard read the default record path as well as the override, and
recorded it **Pass — both are pinned**. Reverting `records` to `{IN_FLIGHT}` — deleting the fix
entirely — left **23 passed, nothing red**. `DEFAULT_IN_FLIGHT` was referenced from one line in the
whole suite, and no test ever placed a record at the default while the override pointed elsewhere,
which is the veto fixture itself.

## And that fix made the mutation harness constant

Worse than unpinned. During a mutation run the harness holds its own record at the default path and
`_guard_says` plants one at the override — two records, two owners — so `owners == {int(announced)}`
was never true, the guard failed on **unmutated** source, and `-x` stopped every run there.

The defect seat's probe is the one that settles it: a mutation that rewrites a word inside a
docstring, which no test can catch.

```
at 3b146f1:  CAUGHT      PROBE: a docstring word no test can catch
after:       NOT CAUGHT  PROBE: a docstring word no test can catch     1 of 13 NOT caught
```

Ownership is judged **per path** now, and the test that plants records skips while a harness run
holds the real one. `--only stranded` is 12/12, and it can still say NOT CAUGHT.

## Veto 2: the row that says the collision does not exist

`CHG-20260830-08` task 12 and `ACC-20260830-08` row 12 still read *"it collides with nothing, which
holds"* — while CHG-20260831-01's headline finding is that `void` collides with *avoid*. Marked.

## The matcher was wrong in three more ways, all in Chinese

`\b` is defined against `\w`, CJK characters are `\w`, and Chinese typography does not space Latin
words. Every boundary rule tried so far was right about English and wrong about Chinese:

| input | was | is |
|---|---|---|
| `通過failed` | a silent **pass** | refused, reads as both |
| `已void` | not a recognised verdict | recognised |
| `通過／未通過` | silently clean | refused, reads as both |
| `尚未完成` (status) | **DONE** | not finished |
| `abandoned` (status) | reads as both | not finished |
| `Voided.` | unrecognised — and the fix it suggested disarmed the void rule | reopens its change |

Boundaries are ASCII word characters, not `\b`. Nesting is judged by **span**, not by comparing
vocabulary entries — that is what tells 未通過 (one word) from 通過／未通過 (two). The rule is now a
shared `_standing`, because the status matcher had never had it: `未完成` and `尚未完成` read as
*finished*, silently, across 127 records, with this lint in CI.

Seven verdict heads and nine status heads are pinned in tables. Every boundary rule so far looked
right on the English cases, so the English cases are not enough.

## Two rulings I asked the risk seat for

**The secret scan has crossed from disclosure into defect.** Measured:
`https://user:sk-ant-SECRET@api.vendor.com/v1` validated clean and was written to the registry and
to `config.sqlite`. Six rounds disclosed only that the key list is non-exhaustive; nobody had
disclosed that the scan read the query string and nothing else. `server.py` already refuses
`parts.username or parts.password` on its own bind URL — the same codebase checked the shape in one
place and not the other. Fixed, with three cases pinned.

**`reach_of` has not.** The heuristic is deliberate and pinned; what was missing is that nothing
said where it had been applied. The console now names the models graded `internal` on a bare host.

The seat's second ground for that one **did not reproduce**: it said the misgrade keeps a model out
of the "N of which leave this machine" count. `leaves_this_machine` is `reach != LOCAL`, so an
internal model is counted there. The real cost is the exemption from the `EXTERNAL and not key_env`
refusal, and that is what the code now says.

## Risk & rollback

  classifies as before, checked; two that could not be written at all now can.
- The guard is stricter per path and laxer per run. A record the announced run owns is excused; any
  other record fails.
- Rollback: revert. The mutation harness goes constant again and a userinfo credential is storable.
