## Absence is cannot-tell

The shape gate added last round to stop a bad `owner` destroying a source file reads
`record.items()` — and a dictionary cannot report a key that is not there. So a hand edit that
**deletes** the `owner` line, rather than mistyping it, walked straight past:

```
record shape                 before        now
no `owner` key at all        DESTROYED     refused, kept
"owner": "nope"              refused       refused
"owner": true                refused       refused   (was unpinned)
```

`_owner` returned `None`, `_alive(None)` returned `False`, and `recover` read that as *"the owner is
gone"*: the file overwritten, the record unlinked. If the owning run is alive that is
CHG-20260830-06's corruption, reached through absence instead of through a type — and the refusal
that names `{'owner': 'str'}` as the wrong field invites exactly the repair that reaches it.

The gate also read **every** key present, so a record carrying a spare field of any other type was
refused with recovery unreachable until the operator guessed which unread field was the problem. It
reads the four fields it uses, and no others.

## `BROKE` asked pytest a question only the module can answer

The outcome added last round for a mutation whose module will not import read pytest's **summary
line**. Pytest only says `error` when the *test* module imports the mutated one at its own scope —
measured, **12 of 32** (tests, module) pairs here do not. For all of those the false green survived
the fix.

Worse, it could not tell an import failure from an ordinary fixture that raises: both print
`1 error`, and the second is a real catch reported as a non-catch, telling the author to re-anchor a
correctly anchored mutation.

The module is asked directly now, in its own interpreter — and by its **package path**, which is a
mistake this change made and caught: importing `src/ai_sdlc_runner/models.py` standalone raises
`ImportError: attempted relative import with no known parent package`, which reported `BROKE` for
four honest mutations in the `reach` group.

## The sentence rule leaked on this repository's own prose

The third formulation required a **capital** after the full stop. Measured over all 265 records:

| what follows a sentence end | count |
|---|---|
| a capital | 4306 |
| a backticked identifier | 428 |
| a lowercase word | 55 |

So roughly one boundary in ten was invisible, and the one shape that still worked was the only one
`GHOST_EXCUSES` pinned. A sentence end is punctuation that is not an abbreviation, followed by
whitespace and something that is not a dash, or by a line end. Six new rows carry it — a backticked
identifier, a lowercase word, a paren, a digit, `etc.`, and the ellipsis.

And the `renamed to …` phrase — the phrasing this file's own comment tells people to write — was
spelled with hard spaces in a ledger whose every record is hard-wrapped. Three of its eight word
gaps refused it.
