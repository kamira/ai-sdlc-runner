## Two findings in the code

### A cross-origin check that compared prefixes

```
http://localhost.evil.example  -> ACCEPTED
http://127.0.0.1.evil.example  -> ACCEPTED
```

`origin.startswith("http://localhost")` is true of any domain an attacker registers under that
prefix. Found by codex-seat **reading** the check; I confirmed it by running it — all three
lookalikes it named were accepted.

The origin is now parsed and required to **round-trip exactly**: scheme, host and port rebuilt and
compared, with any path, query, fragment or userinfo refused. Parsing alone was not enough —
`urlsplit` reads `http://[::1].evil.example` as host `::1` and silently drops the rest, so a
hostname check would still have accepted it. A browser would not send that, but *"browsers only send
well-formed origins"* is exactly the kind of assumption that becomes the next finding. Eight tests.

### `halt_independent` enforces nothing

Graded on `acceptance` at high risk, and the README said *"the verifier must not be the builder"*.
But `STOPPING` treats it identically to `halt`, `engine.py` says in as many words that no ordering
between the stopping values is needed, there is one operator identity, and **nothing records or
compares who confirmed.**

This is task 15's own finding one layer down: independence was "enforced by a button caption", and
the fix moved the caption into a policy table. Not fixed here — closing it needs a second identity,
which nothing in the design has. It is now in **Known gaps** instead of being stated as a property.

## What a newcomer could not do

Both seats walked the path of somebody with the repo checked out, and got stuck in the same place:
the plan example was fenced `jsonc` with `//` comments (`json.loads` rejects it), carried **one node
spec of the fifteen** the walk needs, never mentioned the **`operations`** block every acting node
requires, and nowhere stated **what a dispatched agent must print**.

[`examples/`](../../examples/) now holds a plan that actually runs:

```
runner --config examples/runner.yaml run --plan examples/plan.json --risk low --confirm merge
  → visited 20 nodes, 17 asks, state: finished, and greet.py on disk
```

`examples/agent.py` is also where the **answer contract** is written down — which node must return
`verdict`, which must return `modules`, which must return `module`, and what a seat answers at a
survey versus at a panel. That contract existed only in `engine.py` before.
