### The two guards written to keep two of those true are defeated by a line break

`test_no_sentence_in_this_module_states_a_count_that_disagrees_with_fields` matches
`(one|two|three|four) of the (one|two|three|four) settings` with literal spaces, and
`test_no_requirement_row_counts_the_settings_surface` matches two exact phrases in one file.
Measured by the idiom seat, against the whole suite:

```

the same wrong count, rewrapped across a line     2145 passed

```

And the sentence the second guard forbids in `settings.py` **stands in the test file whose job is
to keep it out** — `tests/test_settings.py` carries `Settings may lower the seat floor and nothing
else.` in a docstring, and `docs/ai-guideline.md` records that this sentence *"was false about
`main` twice over"*.

### `config/settings.json` is neither tracked nor ignored

`git ls-files config/` does not list it; `git check-ignore` exits 1. That is the exact condition
`CHG-20260904-14` shipped a rule for - *"Anything that is neither is the defect this rule was
written for"* - and the rule reads `examples/` only, one prefix away from `settings.py`'s own
`DEFAULT_PATH`. Writing the file the way `runner settings` does makes `tools/frozen_tree.py` report
the tree is not frozen, and the remedy it prints is *commit* - which would publish one operator's
`high_risk_mode: true` to everyone who clones.

## Task 5 - what `policy.py` claims and what holds

> *"These are never `ordinary`, and `settings.load` refuses to accept one in `ordinary_commands`"*

The second half is true and exact: all 63 names in `EXECUTORS` are refused, case-folded. The first
half is not - `_REPO_PATH` is tested before the `EXECUTORS` branch, so a **bare** name with no
arguments is read as a filename:

```
recognise('rm')  recognise('python')  recognise('sh')  recognise('curl')  ->  ordinary
```

Low consequence: a bare word with no arguments genuinely is ambiguous with a path, and anything
carrying an argument or a metacharacter is caught. But the sentence is an absolute, and `README.md`
already has the correctly scoped version - *"can never be **vouched for** as ordinary"*.
