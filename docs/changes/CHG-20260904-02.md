## Read this first

A run can stop in three shapes: a gate, a tie, and a requirement nobody has finished. `cmd_run`
read two:

```python
if stop.get("undecided"):
    ...  # "Offering `--confirm` here would be offering a control that cannot answer
         #  what is being asked."
else:
    print(f"waiting for:   a decision on {stop['gate']} at {stop['node_id']}")
    print(f"continue with: --resume --confirm {stop['gate']}")
```

`intake_review.gate` is `None`. Reproduced end to end:

```
the stop      node_id=intake_review  gate=None  incomplete=True  undecided=False

the terminal  waiting for:   a decision on None at intake_review
              continue with: --resume --confirm None

the engine    EngineError: confirmed gate 'None' does not exist
```

**The objection is written three lines above, in the branch that gets it right.** It was being
offered at the other wrong shape.

`server._require_suspension` was swept for this by CHG-20260903-23 and `console/index.html` renders
all three (`if (s.incomplete) { … no button here … }`). The terminal is the surface nobody swept,
and `grep "waiting for|continue with" tests/` found the server-side guard and nothing for `cli`.
