## The finding

Only the numeric claims about the README's flow diagram are recomputed - "24 nodes" and the rest.
**No test asserts that every graph node id actually appears in the drawing.**

The consequence is specific: a node dropped from the diagram while the count sentence stayed correct
would pass CI. The diagram is complete today, checked by hand during the round - complete by
inspection, not by construction.

## What changes

A test that reads the README's diagram section and requires every `graph.NODES` id to appear in it.
