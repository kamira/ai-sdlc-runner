# CHG-20260828-15 — a module was recorded on the lap the engineer said there was nothing to build

- Project: ai-sdlc-runner
- Branch: claude/chg-20260828-15-module-built-guard
- Date: 2026-08-29 (UTC+0)
- Type: the flow gains the branch it was missing
- Proposed by: `ACC-20260823-51` reservation 2, reproduced by CHG-20260828-12 and handed on
- Risk: **medium** — it changes the module loop's shape, and the loop is also the resume mechanism
- Autonomy: high
- Related: CHG-20260828-12 (reproduced it and named the two designs), CHG-20260823-51 (whose
  reservation this is), CHG-20260827-21 (whose `module_cycle` this moved)

## The gap

An engineer answering `{"module": ""}` — *there is nothing left to build* — still walked
`engineer_build → engineer_selfverify → lead_task_review → record_module`.

`record_module`'s effects are *"tick, commit, update the worklog"*. **A worklog entry would claim a
module that was never built.** `examples/weather-spa` declares those operations, so this was live
rather than latent; `minimal` and `tide-spa` declare none, which is why two of three shipped
examples could never exercise it.

## The design, chosen by the operator

CHG-20260828-12 named two candidates and picked neither, because picking one inside a records pass
would have been the wrong way to decide. The operator chose **the flow branches**:

```
lead_task_review ─pass→ module_built ─yes→ record_module → next_module
re_review        ─pass→      │        └no ──────────────→ next_module
```

The alternative was conditional effects inside `engine`, which is the id-matching this repository
argues against everywhere else — *"declared here rather than matched on the node's id in the
engine"*. A branch says it in the graph, where the flow can be read.

**Both `pass` edges route through it**, so a fix pass that built nothing is caught too.

**Nobody is asked.** What the engineer said is a fact in the run's record, and reading a fact is not
a judgement — the same reason `reconcile` has no role. No supplied decision can answer it, because
a run that could say `yes` could record a module it never built.

**Silence is not a build.** A missing `module` key is `no`, for the reason `_frontier` already
gives: an agent that crashed or replied with prose has not reported building anything.

## What the new edge broke, and what caught it

`module_built --no--> next_module` opened a path **out** of the module loop, and
`graph.module_cycle()` — which bounded on `record_module` — followed it. It began returning
`merge`, `pr`, `lead_review` and the rest, which `engine._MODULE_CYCLE` uses to decide **which nodes
run inside a module's worktree**. The whole change's review would have run in one module's tree.

Bounded on `next_module` now: the cycle is the lap, and a lap ends where the loop turns over.

**It was caught because the cycle is derived from the edges.** CHG-20260827-21 wrote it that way on
the argument that *"a hand-written list of five node ids would leave a node added to the loop later
quietly outside it"*. The list would have stayed correct-looking while the graph moved underneath
it; the derivation moved with the graph and the difference was visible immediately.

## A default dispatcher that modelled a build reporting nothing

Five tests in `test_flow.py` failed. They use `record_module` as *a node that has effects* and had
nothing to do with the module loop — but `Recorder`'s default answer for `engineer_build` reported
no module at all, so every ordinary lap took the empty path.

Nothing had noticed because nothing read it: those tests drive `next_module` from `DECISIONS`, so
the frontier never asked. Fixed at the default — a builder says what it built.

## Risk & rollback

- The loop is also the resume mechanism, which is why the guard reads the run's record rather than
  any state the walk carries: a resumed run reaches the same answer from the same asks.
- The change only ever **removes** a visit to `record_module`. It cannot cause one.
- Rollback: point both `pass` edges back at `record_module` and delete the node. The defect returns.

## Status

**Accepted** — see [ACC-20260828-15](../acceptance/ACC-20260828-15.md).

### Not claimed

**That `record_module`'s effects are otherwise right.** This decides *whether* the node runs. What
its three effects do when they run is untouched, and `weather-spa` is the only shipped example that
declares any.

**That an empty lap is free.** The engineer is still dispatched, self-verify and the review still
run, and only the recording is skipped. Whether the whole lap should be avoided is a different
question about `next_module`, and this change does not ask it.
