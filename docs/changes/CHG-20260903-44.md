## Read this first

`server.Runner` has three methods that take a decision from the operator and append it to state.
One was hardened; two were not.

```
                   names the stop it answers?     stamps run_id?
  approve          yes  (CHG-20260903-34)         yes
  reject           NO                             NO
  rule             NO                             NO
```

`reject` goes from `_require_suspension(undecided=False)` straight to
`self.state.rejections.append(engine.Rejection(gate=gate, node_id=node_id, reason=reason))`,
validating only that the named node has somewhere to send a refusal. Reproduced:

```
run waiting at    plan_confirmed / pm_confirm
POST reject       gate="acceptance", node_id="qa_accept"      -> ACCEPTED

with that rejection planted, and the visible gates blanket-confirmed:
  absent   -> suspended at qa_accept, halt_independent, "it needs a person here"
  present  -> report.rejections records "acceptance at qa_accept was refused by the
              operator", and `acceptance_failed` is entered
```

**A refusal aimed at a stop nobody has been shown redirects the run past the one cell whose whole
meaning is that a person answers the stop they were shown** — recorded as the operator's act.

And `run_id` is `None` on everything the console produces, so the engine's staleness guards —
`if rejection.run_id is not None and rejection.run_id != cfg.run_id:` and the same for rulings —
are unreachable through the only human interface. `Approval`'s own docstring calls `None`
*"the wrong one for an answer typed into a console after a stop"*. This is that console.

`rule` additionally never checks that `node_id` is the node the run is actually undecided at.

## The fix is one helper, not two more copies of the check

Copying `approve`'s eight lines into `reject` and `rule` closes today and leaves a fourth method to
be written without it. `_answering(gate=..., node_id=...)` is the one place the question *"is this
decision about the stop the run is at?"* is asked, and all three call it.

Same move as `models.COMPUTED` (CHG-20260903-39), `_declare_classes` (-41) and
`asks_including_this_one` (-42): when several readers of one fact disagree, the answer is one name
they all read.
