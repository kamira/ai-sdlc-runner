## The gap

`serve` already takes `--risk`, `--sandbox` and `--undeclared`. `--change-class` was registered on
the `run` subparser only.

The consequence was not that a console operator had a smaller vocabulary. It was that
`report.change_class` could only ever read *"nothing was declared"* on the console — so **one of the
five permission ledgers could not exist there at all**, which is why CHG-20260901-15's task list
carried it as a blocker rather than a nicety.

## What it is not

A console cannot **invent** a class. A class relaxes a gate and only a person may declare one —
`plan.check` refuses a plan that classes itself with exactly that argument: *"a plan that could
class itself would be a model granting itself an exemption from the gate that exists to put a person
in front of it."*

So it is declared **at startup**, by the person starting the console, and governs every walk that
console runs — the same parse, the same shape, and the same operator turn `cmd_run` writes.

## The exemption came out with the flag going in

`test_both_ways_to_start_a_run_take_the_same_governance` — the bidirectional drift guard from
CHG-20260901-16 and -17 — carried two entries: `change_class` and `class_by_workstream`. Both were
there because of this gap. Its exemption set is now **empty**, and that is the point: an exemption
that outlives its reason is a permission nobody re-reads.

## Risk & rollback

- **A console can now relax a gate**, on a person's signed and dated declaration, exactly as the
  command line can. That is the point and it is a real widening of what a console operator may do.
- **The class governs every walk that console runs**, not one — it is declared once at startup.
  That is the same scope `--risk` and `--undeclared` already have there, and it is a longer reach
  than `run`'s per-invocation one.
- **The mutation anchor for the attribution moved.** Two commands now write the same operator turn,
  so the one-line anchor matched twice; it is anchored through `cmd_run`'s own comment now, and
  `mutation_check --only voice` still reports **CAUGHT**.
- Rollback: revert. The console goes back to being unable to declare a class, and the two
  exemptions go back into the drift guard.
