## The finding

`tests/test_conversations_sqlite.py` defines `test_one_bad_conversation_does_not_stop_the_others`
twice: at line 254 (CHG-42's, using the `_dirty_legacy` fixture) and at line 417 (CHG-45's,
parametrised over six `DIRT` shapes). Python keeps the second. The first **has not run since CHG-45
landed** - verified: six collected items, all from the parametrised version.

Nothing broke, because the replacement is stronger. It is still dead code sitting in the suite
looking like coverage.

## What changes

The two tests are not duplicates: the older one drives `_dirty_legacy`, a fixture the parametrised
`DIRT` set does not include, and asserts a good conversation **after** the bad one still imports.
That case is worth keeping, so the fix is a rename rather than a deletion.

A second, more useful task: nothing stops this happening again. A test that scans each test module
for duplicate top-level test names would have caught it the day it appeared.
