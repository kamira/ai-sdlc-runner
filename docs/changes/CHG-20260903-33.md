## The defect

```
docs/structure/data.md:134   "…and everything about the governance is in `policy.py`."

store.py:308      CREATE TABLE IF NOT EXISTS halt_routing (kind, recipient)
store.py:486-488  DELETE / INSERT — the project writes its own routing
store.py:491      def halt_routing(db) -> Dict[str, str]
cli.py:933, 1388  store_mod.halt_routing(db) -> RunConfig.halt_routing
engine.py:485     carried on the config
policy.py         routed_to(kind: str, routing: Optional[Mapping[str, str]] = None)
```

**Who a stop is sent to is governance.** It lives in a project store table, the project writes it,
and `policy.py` reads it as an argument. `data.md` names none of this — `halt_routing` appears in
that file **zero** times.

What `policy.py` does own is the **shape** of the answer and the fallback when a project names
nobody, which is `DEFAULT_RECIPIENT`'s whole argument. The paragraph now says that, and says the
names are the project's.

**This matters beyond the sentence**, which is why it is a record rather than a typo fix: the seat's
inference was that a project-configured table reaching `policy` would falsify governing text, and
therefore that `CHG-20260903-24` must not have one. **The text it would falsify is already
falsified**, so that is not the reason. The reason `-24` ships `ANSWERED_FIRST` populated with no
override is the *defect* seat's: a `table=` with no writer is a socket wired to `-25`.

## The second copy, and it is the third of three

`policy.py`'s `GATES` table carried, unqualified, in the comment a reader consults first:

> *"Acceptance. On a high-risk change the verifier must not be the builder."*

`README.md`'s Known gaps has always said the opposite — *"`halt_independent` does not check
independence … there is one operator identity, and nothing records or compares who confirmed against
who built. The name is an intent."* `docs/ARCHITECTURE.md` said the same thing unqualified and was
corrected by **CHG-20260903-27**. This was the third copy, and the one inside the governance table
itself.

Also corrected there: what `halt_independent` *does* enforce is now stated — it stops for a person,
and a blanket `--confirm` does not open it (CHG-20260903-27) while a person answering the stop can.
