## The finding

Deleting the whole `drawFlow` / `drawModels` chain from `src/ai_sdlc_runner/console/index.html`
leaves the suite green. The only page-content tests today are
`test_the_console_has_a_handler_for_every_button_it_draws` and one `"here.rejects_to" in page`
substring check; neither touches the diagram, the layout code, or the models panel.

Both engines found this independently; the codex engine rated it a FAIL of CHG-20260823-12.

## What changes

There is no JavaScript engine in this repo's test environment and adding one is a different change.
What is available is the page's own source, and the honest fix is to say so: these are **structural**
tests, named as such, that fail when the chain is cut.

Three properties are worth pinning, and each is a thing that has to exist for the panels to work at
all:

1. every endpoint the page needs is actually requested by the page;
2. the flow panel is drawn by a function the page reaches from its snapshot path;
3. the models panel can say a model is dispatched **nowhere** - the sentence CHG-12 exists for.
