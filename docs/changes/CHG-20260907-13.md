## The finding, in one sentence

**The guards prove a true sentence is present. None checks that a contradicting sentence is
absent.**

```python
assert f"{built} of {built} tables" in catalogue        # built == len(store._EXPECTED) == 6
```

Green — while the same file's section 14 **heading** read *"SQLite DDL — three of five tables
built"*, and `docs/DATABASE.md` read *"Five tables, and all five are built"*, and `README.md` read
*"three of its five tables are built"*.

The history is the finding rather than an illustration of it. `CHG-20260903-37` found `SCHEMAS.md`
row 14 saying "3 of 5" against `DATABASE.md`'s "6 of 6", corrected the row, and added that guard.
`DATABASE.md:14` records the repair in its own words — *"That row now carries the same number."* It
did. The **heading of the section that row belongs to** still said three of five, `README.md` still
said three of five, and the guard installed to prevent exactly this is structurally incapable of
noticing either. `git log -S` puts the heading at CHG-20260823-25 and shows CHG-37's commit
changing **one line** of `SCHEMAS.md`.

The same shape, twice more: the denial *"`conversations` and `turns` are not created by any code
yet"* was repaired on `DATABASE.md` and given a guard that reads **that one file**, and the same
sentence sat in `SCHEMAS.md` for four more days. And `API.md`'s route count moved to nineteen while
`SCHEMAS.md` and `README.md` kept saying seventeen.

### One item that is not a wrong number

A reviewer refused `DATABASE.md:192` as a count defect, and measuring settles it: section 2 holds
exactly **five** `CREATE TABLE` blocks and `halt_routing` lives in §0.2. The sentence is true of
its section and contradicts line 3 only on the page's face. A count grammar would report *"says 5,
is 6"*, which is not what the sentence says. Its repair is the **scope** — *"The five tables in
this section"* — and the other reviewer, which had wanted every claim to name its authority,
accepted the qualification that follows from it:

> a bare noun identifies the global authority only where the claim does not narrow its own scope.

That sentence is now the one entry in `COUNT_MENTIONS`, and it is there for that reason.

## What ships, and one thing that deliberately does not transfer

1. **A count grammar keyed on the noun.** `fields` needed `listed in \`module.NAME\`` because three
   different things have fields. There is one set of tables and one set of routes, so the noun *is*
   the referent — and the two claims that were wrong live in a Markdown **heading** and a **table
   cell**, neither of which can carry an identifier. Both reviewers agreed after the second round;
   one had proposed carrying the identifier everywhere and withdrew it on that evidence.
2. **`_prose`** — fenced code, `>` blocks and the `*"…"*` withdrawn-sentence form removed before
   anything is scanned. This is what buys strictness: the repository *keeps* wrong sentences on
   purpose, so a checker that had to tolerate them would need an allowlist, and an allowlist over
   prose is one `or` away from proving nothing. Measured before it existed, the raw sweep reported
   three false positives — a `3 of 5` inside a blockquote, a `CREATE TABLE` inside a fence, and a
   diagram in `README.md`. With `_prose` they are gone and **only real claims remain**.
3. **A strict denial rule over every document**: no allowlist, no second phrasing accepted "just in
   case". `test_a_withdrawn_sentence_is_ignored_only_where_it_is_marked_as_one` pins `_prose` in
   **both** directions, because a stripper that removes too much proves nothing either — including
   that an ordinary inline quotation still reaches the rule.
4. **`docs/DATABASE.md` joins the sweep**, measured first: it contributes one claim and one
   scope-narrowed mention and breaks nothing.
5. **The number in a JSON sketch is deleted, not corrected.** `"kind": "<one of \`conversations.KINDS\`>"`
   delegates membership and growth to the authority; a referent that replaces a count cannot drift.
   Both reviewers preferred this to synchronising a number nobody can check.
6. `formats` gets **no grammar**. One reviewer's words: a recogniser whose entire live language is
   a single heading is a bespoke assertion disguised as infrastructure. The heading names
   `conversations.FORMATS` and the existing per-section name check covers membership.

## What this does not fix, stated rather than implied

There is no general rule for a sentence that denies a status in words nobody anticipated. Both
reviewers said so independently, and one put the limit plainly: *"A claim written in genuinely
novel unrestricted English can still escape. Saying otherwise would reproduce the same false
assurance this finding exposes."* What is defensible is the four controls: a family recogniser
where the language supports one, a strict predicate after structural stripping, deleting the
driftable claim in favour of an authority, and a **sweep by entity name recorded in the ACC** — the
repair step CHG-20260903-37 skipped when it grepped for the stale *number* instead of the table
names.
