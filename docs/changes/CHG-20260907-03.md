## The finding, and that the two engines disagreed about it

Reported by the **defect seat** (`fable`) in round thirteen. `_strings` reads a seat's answer for
`missing`, `problems` and `unsafe`. Its comment ended:

> *A falsy scalar means the seat said nothing; a truthy one that is not text is still not text, and
> reading it as a problem invents one.*

The code did the opposite for truthy non-text — in **both** its branches. Measured:

```
_strings(True) -> ['True']                _strings(False) -> []
_strings({'a': 1}) -> ["{'a': 1}"]        _strings(0)     -> []
_strings([{'issue': 'rm -rf /'}]) -> ["{'issue': 'rm -rf /'}"]
_strings([True, 1, None])         -> ['True', '1', 'None']
```

Three positions were on the table and the two engines took different ones, so the disagreement is
recorded rather than averaged.

## The measurement that chose between them

Three seats answering `{"unsafe": [{"issue": "rm -rf /"}]}`, driven through the engine:

```
today                       halted=intake_review   safety={seat: ["{'issue': 'rm -rf /'}"]}   merge=False
dropping in the fallback    halted=intake_review   safety={seat: ["{'issue': 'rm -rf /'}"]}   merge=False
dropping in both branches   halted=done            safety=None                                merge=True
```

**`codex` proposed dropping, in the scalar fallback only.** Measured, that is *inert on the
documented shape*: `docs/SCHEMAS.md` documents a list, the list branch is untouched, and the run
behaves exactly as it does today. It does not reach the case it was proposed for.

**Extending it to both branches** — the consistent version — walks a run whose three seats all
called the requirement unsafe to `merge`, with `safety=None`. That is `CHG-20260906-07`'s unanimous
finding returning through another door, and worse than the one `CHG-20260907-01` closed: that
counted silence as agreement; this turns a seat that spoke into silence first.

**Keeping the repr** — my own first position, and what the code does today — leaves a person making
a safety decision about a Python repr. `cli.py` prints `unsafe: risk: {'issue': 'rm -rf /'}`, and
`--proceed-unsafe` spends its `shown_digest` against that repr.

So: refuse. It is the only option that neither invents a finding nor loses one.

## What the seat corrected in my brief

Three things, and each moved the change:

1. Both `str()` calls came from **one** commit (`ee8bfc1`, CHG-20260823-13). CHG-20260903-36 only
   ever touched the fallback — the list branch has never been swept. So this is one defect, and
   repairing half of it is what left it open.
2. `{"problems": true}` does **not** stop the run today: the engine stops only when `missing` or
   `safety` is non-empty, so the fabricated `risk: ['True']` reaches `report.survey` and no person.
   The one that reaches a person is `unsafe`.
3. `IntakeError` from `collect` is caught by `cli.run` (CHG-20260901-17) and printed as one
   `halted:` line. Refusing is a sentence, not a crash.

And one I got wrong myself and corrected: I first reported that the seat's measurement refuted
`codex`'s proposal. It refutes the *extended* version. `codex`'s actual proposal fails differently
— it does nothing at all to the shape the documents describe.

## What changes

```python
def _text(item, where):        # one item, or None if the seat said nothing there
def _strings(value, where)     # a list goes item by item through _text; a scalar goes straight
```

Callers name what they are reading: `seat 'risk', 'unsafe'[0]`, `the options offered for 'ui'[1]`.
`collect` aggregates four seats, and *"something was not text"* is not actionable.

The falsy rule is kept and **extended item-wise**, so `['', None]` is `[]`. That is consistent with
CHG-20260903-36 rather than a second decision — and it is the one judgement here that could
reasonably go the other way, recorded as such.

## A thing it fixes on the way

`read_options` refuses fewer than three options because *two is a false choice*. Three objects
passed that count and reached a person as `["{'a': 1}", "{'b': 2}", "{'c': 3}"]` — three of
nothing. They are refused now, by the same rule and without a second one.
