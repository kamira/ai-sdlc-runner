## The finding

`/project`, POST `/models/:id/test`, DELETE `/models/:id`, GET/PUT `/config/panel`, POST
`/run/resume`, GET `/run/objections/:node` - and describes a six-phase screen strip (*Plan, Assess,
Build, Review, Verify, Ship - the current one lit*) that exists nowhere.

Neither appears in any task's done-when, so the State column is not false. A reader of the design
section is nonetheless told about things that were never built.

## What changes

The record is annotated **in place with a note**, per this repo's convention for a record that was
actually wrong: the six endpoints and the phase strip are marked as designed and not built, naming
the round that established it. Nothing is deleted - what was proposed is part of the history.
