## The finding

`docs/defect-log.md` is **not** in `test_documented_numbers.py`'s DOCS tuple, so its figures are never
machine-checked - inside a change whose record claims *"every figure in it is recomputed"*.

It has already been wrong twice, and the file says so itself: a summary reading *"two of
thirty-two"* against a table summing to 35, and *"four of these thirty-five"* against a table
summing to 65, shipped through six changes.

Adding the whole file to DOCS is the wrong fix: the file **quotes those historical wrong figures on
purpose**, and a blanket numbers check would fail on the quotations.

## What changes

A targeted check instead. The log's group headings carry their own counts - `## Found by an
independent seat - 13`, `## Found only by running it - 9` - and each group's entries are the `###`
subsections beneath it. That is recomputable without touching a single quoted figure.
