## What was built

A tide-table SPA — four modules, no build step, no dependencies — driven through the runner:

```
visited:  35 node(s)
asks:     26
stopped at: done — nothing further was asked for
state:    finished
```

`site/index.html`, `styles.css`, `tides.js`, `app.js`. The page renders the current level, the next
six tides and a twelve-hour curve on a canvas. The model is checkable from the output: 09:19 → 15:31
is 6h12m, exactly half the 12h25m semidiurnal period, and 0.70 / 5.50 m is mean 3.1 ± amplitude 2.4.

The conversation is stored: **56 turns** — 26 asks, 26 answers, an operator decision, opened and
closed — and exports as JSON, Markdown and CSV.

## The defect it found

`resume_or_open` set `_opened = False` when the store read failed — meaning *"so open it"* — and
then **returned without opening**. Every turn of that run failed:

```
conversation store failed: turn 0 (opened): refused: no conversation at ….jsonl to append to
conversation store failed: turn 1 (ask):    refused: no conversation at ….jsonl to append to
…
```

once per turn, and the whole conversation went to stderr instead of to disk.

**No test reached it** because every test either starts clean or resumes a store that still has the
file. A journal that outlives its store is what a real machine produces — a store root that moved, a
temporary directory cleaned, a `--store-root` typed differently the second time.

Now reopened, under the marker's id, so a resumed run keeps the identity it was given. Pinned by a
test that deletes the store and keeps the journal.

## And the long-path hazard bit again, in a real run

The first attempt failed on every turn for a different reason:

```
cwd length  : 188
full length : 282   MAX_PATH is 260
over by     : 22
```

The **directory** (243 chars) was created; the **file** (282) could not be. Windows reports that as
`FileNotFoundError` about a directory that demonstrably exists — the failure `attachments.py` has a
constant and three paragraphs about, and which a seat reproduced against the conversation store in
round 2 of CHG-20260823-25.

**It was visible only because of the fix that round produced.** Before the stderr channel existed,
this run would have reported `state: finished` with an empty store and said nothing. The mechanism
worked on the first real occasion it had to.
