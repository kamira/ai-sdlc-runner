## Read this first

`Survey.as_dict()` has four keys, and two of them are `seat -> [line]` maps:

```
complete   bool
missing    list
problems   {seat: [line]}
safety     {seat: [line]}
```

The block that draws it did:

```js
block("surveyed", Object.keys(state.survey).sort().map(function (k) {
  return k + ": " + String(state.survey[k]);
}));
```

`String({...})` in JavaScript is `"[object Object]"`. So a run whose seats raised three problems
and called something unsafe rendered:

```
complete: true
missing:
problems: [object Object]
safety: [object Object]
```

## Where it mattered, which is not where it looks like it matters

Line 720 of the page:

```js
drawFlow(); drawLog(); drawDecisions(); drawAsk();
```

Both run on **every** render. The `surveyed` block is in `drawDecisions`, so it is always drawn.
The readable rendering of `safety` — attributed, in red — is `drawUnsafe`, and that is called only
from inside `drawAsk`'s suspension branches.

So on a **finished** run, which is when a person reads back what the seats said, the only place
those words appeared was this block, and there they were `[object Object]`.

## What changes

The block renders by value shape: a map becomes one attributed line per thing said, a list is
joined, a scalar is printed. An empty map prints `none` rather than vanishing — a key that renders
as nothing is indistinguishable from a key that is absent, and a seat finding nothing is a result.

```
complete: False
missing: ui
problems: risk: no screen described
safety: defect: the migration drops the audit table
safety: risk: it deletes user data
```

The attribution is the point: `problems` and `safety` are keyed by **seat** rather than by aspect,
and `CHG-20260903-37` is the record of a caller that keyed by aspect and matched nothing, ever.

## The guard, and what it honestly cannot do

There is no `node` on this machine, so the rendering cannot be executed here. The test asks
`_console_code()` — the page with every comment stripped, which exists because *"the first version
of the guard below was satisfied by its own comment"* (CHG-20260904-11) — and asserts three things
chosen so that each plausible reversion removes one of them:

| assertion | what removing it means |
|---|---|
| `String(state.survey[k])` absent | the whole repair reverted |
| `typeof v === "object"` present | the map branch made dead |
| `seat + ": " + line` present | the attribution dropped |

Both mutations below trip an assertion rather than passing in silence, which is the property that
matters. The record says plainly that this is a text guard: it is the strongest thing available
without a JS engine, and the mutations are the pin.
