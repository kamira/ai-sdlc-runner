### A1 分析(analyst)
- **職責**:把需求轉成可執行的依據——AI Guideline、四種結構、影響分析 / 模組切分建議。
- **輸入**:需求(口語/文件)。**輸出**:`docs/ai-guideline.md`、`docs/structure/*`、影響分析。
- **可做**:釐清、設計、定介面契約與驗收條件。**擁有使用者問答**(代問):與使用者往復到需求完全了解,再上交**企劃**——主決策 agent 讀企劃、永不讀逐字稿。**不可**:寫實作程式碼。
- **階段**:需求分析 + 結構設計。**交給**:orchestrator(企劃 → 審議會共同審議)→ I1(附模組切分與整合點)。
