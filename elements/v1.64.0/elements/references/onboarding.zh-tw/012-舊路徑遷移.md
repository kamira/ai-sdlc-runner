## 舊路徑遷移

帳本已經在某處、但要換落點時(例如 `docs/` 後來被 site generator 佔用):

- **只搬我方檔案**:`CHG-*.md`、`ACC-*.md`、`structure/`、`knowledge/`、`ai-guideline.md`。
  認的是「這是什麼」,**不是「在哪個目錄底下」**——別人的檔一個都不動。
- **`git mv`**,讓歷史跟著走。非 git 專案降級為複製 + 刪除,並在 ack 中聲明。
- **預設 dry-run**:先印完整搬移清單,確認後才動。在別人的 repo 裡搬檔是不可逆方向。
- **可續跑**:中斷後重跑只搬剩下的,不留半套。
- 遷移本身開一筆 CHG,並在 Guideline 表頭更新落點。

機器輔助:`scripts/ledger_migrate.py`(預設 dry-run)。
