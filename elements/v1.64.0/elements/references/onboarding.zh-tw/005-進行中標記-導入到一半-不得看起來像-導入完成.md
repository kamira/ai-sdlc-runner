## 進行中標記:「導入到一半」不得看起來像「導入完成」

路由判準是「找得到帳本」,而**帳本在 onboarding 途中就會變成找得到**——
`init` / `adopt` 只要建出第一個 `CHG-*.md`(或第一個 `changes/` 目錄)就中斷,
下一次進場會掃到帳本、判為「已治理」,然後**跳過剩下沒做完的步驟**。
半套的骨架就這樣直接進了變更流程,而且沒有任何東西抗議。

所以 onboarding **第一個動作**是寫標記,**最後一個動作**才是移除它:

```
<root>/.onboarding        # 內容:INIT|ADOPT + 進行到哪一步 + 時間(UTC+0)
```

- **進場時標記還在** → 上一次的 onboarding 沒做完。**不得往下走變更流程**,
  先從標記記的步驟續作(見上方「不覆寫、可續跑」),完成後才移除標記。
- 標記與 handshake 的關係:handshake 第 5 步對帳讀到它,視同「未收尾階段」處理。
- 這是「最後一次行為紀律」在 onboarding 上的實例:動手前意圖先落盤,
  做完立刻記結果。守住它,中斷與正常結束留下的狀態是可分辨的——
  而**可分辨**正是這裡唯一要的東西(KN-003:「做到一半」與「做完了」必須分得開)。
