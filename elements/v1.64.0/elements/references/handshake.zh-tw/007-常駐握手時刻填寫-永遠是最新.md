## 常駐握手(時刻填寫、永遠是最新)

ack 不只是說進對話——**它是一個檔案,而且隨時保持最新**。進場時把 ack 寫進 `docs/worklog/handshake-<agent-id>.md`;**每個步驟邊界都更新**(步驟完成的那一刻,跟該步的落盤一起做):

```
分支/角色/範圍:<…>
現在做:CHG-… 步驟 <n>/<m>
下一步:<一句話>
最後更新:YYYY-MM-DD HH:MM(UTC+0)
```

這是最後一次行為紀律作用在握手本身:**任何**時刻被中斷,檔案都是最新的,下一個 session 的進場握手直接把它當作精確續作點——不用重建、不用猜。單人接續用一個檔;並行 agent 一人一檔(比照 worklog 慣例:收尾歸檔)。
