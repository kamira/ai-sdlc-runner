## 選配前置:發散–收斂(adhd)

鎖定計畫前(或結構設計時),當解空間寬,跑一次**主線內聯、序列**的發散→收斂——改編自 adhd 方法——避免過早收斂:

- **發散**:在不同框架下(反轉問題、去約束、跨域移植、推極端)產生多個候選 task 拆解 / interface 設計;暫停評判。
- **收斂**:critic 評分(可行性 / 契合 / 陷阱)、聚類、留存活者。
- **只內聯**:主線序列跑——本環境平行子代理 fan-out 會停滯;不用常駐 agent。
- **回填帳本**:選定的拆解落入 CHG tasks、理由落入決策表——**不另立構想文件**(禁 parallel ledger)。

這是計畫 / 結構閘的選配思考輔助,不是 runner 階段。
