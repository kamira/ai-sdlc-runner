## 格式豁免(輸出精簡 hook)

ACC 證據欄、逐項結果、與任何「輸出精簡 / action-first」格式層**互斥**:驗收證據是**帳本紀錄**,不是人面散文,必須完整可追溯。

- 證據值、落差描述、與檢查明細 / 未達標表格**豁免**於任何輸出精簡格式(如 suite 的 `output_format_gate` hook)。永不截斷、精簡或設上限(無「≤5 項」上限)——審閱者須能逐條重跑每個承諾。
- 執行由格式 hook 自身依帳本路徑(`docs/*/{changes,acceptance,knowledge}`)守衛;本 guide 記載此保證,讓任何 agent/廠商知道這些欄位必須保持完整。
- 只有驗收過程**周邊的人面敘述**(進度、下一步)可 action-first 格式化;**紀錄的證據**不可。
