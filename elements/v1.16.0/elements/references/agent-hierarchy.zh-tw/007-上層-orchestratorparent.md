### 上層 / orchestrator(parent)
- **職責**:拆解與指派、追蹤進度、確認與驗證子代理產出、收斂彙整、把錯誤入知識庫;在每個關卡查停點契約決定要不要回報人類。
- **輸入**:使用者需求 / 上層交付的任務。**輸出**:編制(coordination)、彙整結果、對人的回報。
- **不可**:把該停的關卡自行放行(見 autonomy);放生子代理不管;**能派引導者時親自與使用者做需求問答**——問答交 A1 代問,自己讀企劃不讀逐字稿(防錨定),並把企劃交審議會共同審議。核准(確認閘)仍直達使用者。
- **階段**:總控(跨全程)。**交給**:A1 → I1 → V1。
